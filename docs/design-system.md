# Дизайн-система FuckSobes

Тёмный «пульт управления»: графитовые панели на почти чёрном фоне, один лаймовый акцент `#d3fb52`, белый текст, как вывод в консоли. Плотно и технично, но без шума. Токены заданы в `@theme` в [`src/styles/global.css`](../src/styles/global.css), Tailwind генерирует из них утилиты (`bg-carbon`, `text-fog`, `rounded-card`).

## Принципы

1. **Один акцент.** Лайм единственный хроматический цвет. Не добавляем зелёный, красный, жёлтый: состояния различаем формой (пометка, форма элемента), а не цветом.
2. **Акцент как краска, а не заливка.** Он живёт в обводках, свечении, градиентном слове заголовка и ссылках. Залитая лаймом поверхность допустима только для главной кнопки, текст на ней `on-accent` (тёмный).
3. **Свечение вместо тени.** Возвышение передаётся `shadow-glow`, тени не используем. Единственное исключение: `shadow-nav` под плавающей шапкой.
4. **Мягкие формы.** Карточки скруглены по 30px, шапка по 60px. Углы 4-8px не используем.
5. **Тёмная тема одна.** Светлой темы нет: `color-scheme: dark`, классов `dark:` в коде нет.

## Цвета

| Токен | Значение | Роль |
|---|---|---|
| `ink` | `#0e0e0e` | Фон страницы, самый глубокий слой |
| `carbon` | `#191919` | Панели: шапка, карточки, блоки кода |
| `smoke` | `#2c2c2c` | Разделители, фон inline-кода |
| `graphite` | `#414042` | Рамки повышенных панелей, цитаты |
| `steel` | `#58595b` | Плейсхолдеры, неактивные иконки |
| `slate` | `#6d6e71` | Приглушённые подписи |
| `fog` | `#a7a9ac` | Вторичный текст, описания, счётчики |
| `ash` | `#d1d3d4` | Основной текст ответов, ссылки навигации |
| `paper` | `#ffffff` | Заголовки, числа, текст на тёмном |
| `accent` | `#d3fb52` | Акцент: ссылки, фокус, свечение, градиентное слово |

Прозрачные белые линии: `border-white/10` для рамок карточек, `border-white/8` для шапки.

## Типографика

- **Inter Variable** (`font-sans`): интерфейс и заголовки. Вес 500 для заголовков, 400 для текста, 600 для логотипа.
- **JetBrains Mono Variable** (`font-mono`): счётчики, идентификаторы, поле поиска, код. Шрифты подключены пакетами `@fontsource-variable/*`, внешних запросов нет.

| Роль | Размер | Вес | Межстрочный | Пример |
|---|---|---|---|---|
| Заголовок главной, крупная строка | `clamp(48px, 12vw, 128px)` | 700 | 1, трекинг −0.045em | «413 вопросов» |
| Заголовок главной, малая строка | `clamp(20px, 3.4vw, 36px)` | 500 | 1.2 | «с реальных собеседований» |
| Заголовок страницы | 36-48px | 500 | 1.1 | `h1` категории и вопроса |
| Заголовок карточки | 24px | 500 | 1.25 | `h2` в `CategoryCard` |
| Счётчик карточки | 18px, mono | 400 | 1.3 | «88 вопросов» |
| Текст | 16px | 400 | 1.5 | ответы (`prose`) |
| Описание | 14px | 400 | 1.5 | текст в карточке |
| Моно-подпись | 12-13px | 400 | 1.4 | подписи, метки |

Заголовки крупнее 30px держим плотно (1.0-1.1) и добавляем `text-balance`. Текст мельче 14px не используем, кроме моно-подписей.

## Форма и отступы

- **База 8px.** Шаги: 8, 16, 24, 32, 48, 64, 96.
- **Контейнер:** `max-w-page` (1200px) для главной, `max-w-3xl` для чтения (категория, вопрос), боковой отступ 16px (24px от `sm`).
- **Радиусы:** `rounded-card` 30px (карточки), `rounded-nav` 60px (шапка), `rounded-panel` 16px (блоки кода, выпадающий поиск), `rounded-input` 10px (пункты списков), `rounded-full` (поле поиска, полосы).
- **Внутренний отступ карточки:** 32px. Расстояние между карточками: 20px. Заголовок главной центрируется, всё остальное выровнено по левому краю.

## Свечение

| Токен | Где |
|---|---|
| `shadow-glow` | Наведение и фокус на карточке |
| `shadow-glow-soft` | Поле поиска, выпадающие результаты |
| `shadow-nav` | Плавающая шапка (единственная настоящая тень) |
| `body::before` | Общий лаймовый ореол под шапкой |

## Состояния и доступность

- **Фокус:** контур 2px `accent`, смещение 3px, для всех интерактивных элементов (`:focus-visible` в `global.css`).
- **Выделение текста:** фон `accent`, текст `on-accent`.
- **Движение:** переходы 200-300мс. Под `prefers-reduced-motion` анимации отключаются.
- **Контраст:** `fog` и светлее на `carbon` проходят AA. `steel` и `slate` только для плейсхолдеров и неактивных иконок, не для текста, который нужно прочитать.

## Что нельзя

- Добавлять цветные акценты помимо лайма.
- Использовать серые или белые заливки для главной кнопки: только `accent` с текстом `on-accent`.
- Использовать тени для возвышения (кроме `shadow-nav`).
- Использовать радиусы 4-8px на карточках и кнопках.
- Центрировать длинный текст: по центру только заголовки и вступительные блоки.
- Добавлять светлую тему или классы `dark:`.

## Как расширять

1. Новый цвет, радиус или тень: добавить токен в `@theme` в `global.css`, затем описать здесь.
2. Повторяющийся элемент (встретился три раза): вынести в компонент в `src/components/` и добавить в таблицу выше.
3. Не писать в разметке цвета литералами (`#d3fb52`, `bg-[#191919]`): только токены. Исключение: радиальные градиенты свечения, где Tailwind не принимает токен внутри `rgb()`.
