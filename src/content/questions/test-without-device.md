---
title: "Как тестировать приложение без физического устройства?"
category: tooling
order: 37
---

Основной способ — **iOS Simulator** из Xcode: он запускает приложение на Mac для разных моделей iPhone и iPad и версий iOS, позволяет менять размер экрана, ориентацию, тёмную тему, язык, размер шрифта и геолокацию, а также имитировать жесты, предупреждение о нехватке памяти и отправку push-уведомлений (через файл `.apns`). Работает быстро и подходит для UI- и unit-тестов, в том числе в CI.

Ограничения симулятора: нет камеры, Bluetooth, реальных датчиков, Face ID и Touch ID (только эмуляция), другая производительность и память (он использует процессор и память Mac), а часть API работает иначе. Поэтому финально проверять нужно на реальном устройстве.

Дополнительные варианты: SwiftUI Previews для быстрой проверки экранов, облачные фермы устройств (Firebase Test Lab, BrowserStack, AWS Device Farm) для запуска на реальных телефонах, TestFlight для проверки сборки у тестировщиков.
