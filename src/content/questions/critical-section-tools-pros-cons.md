category: concurrency

Для защиты критической секции (общего изменяемого состояния) используют несколько инструментов:

- **Serial `DispatchQueue`**. Плюсы: просто, нет ручных блокировок, `async` не блокирует вызывающий поток. Минусы: `sync` из этой же очереди даёт deadlock, из `async` нельзя синхронно вернуть значение, есть накладные расходы на переключение.
- **Concurrent-очередь + `.barrier`**. Плюсы: чтения идут параллельно, запись эксклюзивна, подходит для схемы «много читателей, один писатель». Минусы: сложнее в коде, barrier работает только на собственных concurrent-очередях (не на глобальных), при блокировках возможен thread explosion.
- **Блокировки** (`NSLock`, `NSRecursiveLock`, `os_unfair_lock`, `OSAllocatedUnfairLock`). Плюсы: самый маленький overhead, быстрая защита коротких секций. Минусы: `unlock` вызывается вручную (спасает `defer`), легко получить deadlock, `NSLock` и `os_unfair_lock` не рекурсивные, блокируют поток.
- **`DispatchSemaphore(value: 1)`**. Плюсы: понятная идея, работает с любым кодом. Минусы: у семафора нет владельца, возможна priority inversion, легко заблокировать поток пула.
- **Атомарные операции** (пакет Swift Atomics). Плюсы: нет блокировок, быстро для одного значения. Минусы: подходят только для простых значений и счётчиков, а не для составных инвариантов.
- **`actor`**. Плюсы: изоляция проверяется компилятором, ручных блокировок нет. Минусы: обращение только через `await`, возможна reentrancy (состояние может измениться между `await`), работает только внутри Swift Concurrency.

Выбор зависит от задачи: для короткого доступа к одному свойству подойдёт lock или очередь, для схемы чтение/запись — barrier, для нового кода на Swift Concurrency — actor.

```swift
final class Cache {
    private let lock = NSLock()
    private var storage: [String: Data] = [:]

    func value(for key: String) -> Data? {
        lock.lock(); defer { lock.unlock() }
        return storage[key]
    }

    func set(_ data: Data, for key: String) {
        lock.lock(); defer { lock.unlock() }
        storage[key] = data
    }
}
```
