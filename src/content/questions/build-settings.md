---
title: "Что такое Build Settings?"
category: tooling
order: 42
---

**Build Setting** (настройка сборки) — переменная, которая содержит информацию о том, как должен быть выполнен конкретный аспект процесса сборки: например, версия языка Swift, флаги оптимизации компилятора, путь для поиска заголовков, идентификатор бандла, уровень оптимизации и десятки других параметров.

Настройки задают на нескольких уровнях, и более специфичный уровень перекрывает более общий:

1. значение по умолчанию для платформы;
2. значение из `.xcconfig`-файла, подключённого на уровне проекта;
3. значение, заданное вручную на уровне проекта;
4. значение из `.xcconfig`-файла, подключённого на уровне таргета;
5. значение, заданное вручную на уровне таргета — самый высокий приоритет.

Помимо встроенных, можно объявлять собственные **User-Defined**-настройки — переменные, которые затем используют, например, в Run Script фазах или в `Info.plist` через `$(MY_SETTING)`.

Настройки удобно выносить в `.xcconfig`-файлы вместо ручного редактирования через интерфейс Xcode: так их проще просматривать в diff, переиспользовать между таргетами и версионировать, не трогая громоздкий `project.pbxproj`.
