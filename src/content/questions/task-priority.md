---
title: "Как устроены приоритеты Task?"
category: concurrency
order: 92
---

Приоритет задаёт структура `TaskPriority`: `.high`, `.medium`, `.low`, `.userInitiated`, `.utility` и `.background`. Они соответствуют классам QoS в GCD: `.high` совпадает с `.userInitiated`, `.low` — с `.utility`, `.medium` — значение по умолчанию между ними.

```swift
Task(priority: .background) { await syncData() }
let current = Task.currentPriority
```

Правила наследования:

- неструктурированная `Task { }` наследует приоритет и актор текущего контекста; если создаётся из основного потока, получает высокий приоритет;
- дочерние задачи (`async let`, `TaskGroup`) наследуют приоритет родителя;
- `Task.detached` не наследует приоритет создателя: если приоритет не указан, используется значение по умолчанию.

Система может временно повышать приоритет (priority escalation): например, если высокоприоритетная задача ждёт результата низкоприоритетной. Для работы, видимой пользователю, используют `.userInitiated`, для долгой фоновой (синхронизация, загрузки) — `.utility` или `.background`.
