---
title: "Что такое guard?"
category: swift
order: 92
---

`guard` проверяет условие и, если оно не выполняется, обязательно выходит из текущей области (`return`, `throw`, `break`, `continue` или вызов функции, возвращающей `Never`). Он удобен для ранних выходов: проверяем требования в начале функции и дальше пишем основной сценарий без вложенности.

```swift
func show(_ user: User?) {
    guard let user else { return }        // дальше user — не опционал
    guard user.isActive else { return }
    print(user.name)
}
```

Переменные, развёрнутые в `guard let`, остаются доступны после него в оставшейся части области видимости, в отличие от `if let`. Ветка `else` обязана завершить выполнение; компилятор проверяет это на этапе компиляции.
