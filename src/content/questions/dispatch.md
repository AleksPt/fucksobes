> Диспетчеризация метода — это то, как программа определяет, какой код выполнить при вызове функции.

Диспетчеризация — процесс определения, **какую конкретную реализацию метода или функции вызвать** в ответ на вызов, исходя из контекста (например, типа объекта, вызывающего метод). Она нужна для полиморфизма, динамического поведения и других ключевых концепций. Она позволяет:

1. **Правильно вызвать метод при полиморфизме.** Если несколько типов (классы, структуры или протоколы) реализуют один и тот же метод, диспетчеризация определяет, какой метод использовать для конкретного типа.
2. **Реализовать динамическое поведение при наследовании и переопределении.** В иерархии классов вызывается переопределённый метод подкласса, даже если вызов идёт через ссылку на базовый класс.
3. **Соблюдать контракт интерфейсов и протоколов.** Метод вызывается у объекта, соответствующего протоколу, даже если реальный тип неизвестен на этапе компиляции.
4. **Оптимизировать производительность** за счёт выбора статической или динамической диспетчеризации.

**Виды диспетчеризации**

- **`Direct Dispatch` (статическая)** — самая быстрая. Адрес вызываемой функции определяется во время компиляции, поэтому затраты на вызов минимальны. Чтобы использовать статическую диспетчеризацию, помечайте методы `private` или классы `final`.
- **`Table Dispatch` (динамическая)** — распространённый тип. Адрес функции определяется во время выполнения. У каждого подкласса есть собственная таблица с указателем на функцию для каждого метода; новые методы подкласса добавляются в конец таблицы. Во время выполнения к таблице обращаются, чтобы определить метод. В Swift есть два подтипа:
    - **`Virtual Table`** — используется при наследовании классов, что приносит дополнительные затраты;
    - **`Witness Table`** — используется для реализации протоколов, наследования нет.
- **`Message Dispatch` (отправка сообщений)** — самый медленный. Обеспечивает работу таких механизмов, как KVC/KVO или Core Data (?). Главная особенность — возможность менять поведение отправки во время выполнения с помощью swizzling.
