---
title: "Что такое forEach, map, flatMap, compactMap, filter и reduce?"
category: swift
order: 96
---

Это функции высшего порядка для последовательностей:

- `forEach` вызывает замыкание для каждого элемента и ничего не возвращает; из него нельзя выйти через `break` или `continue`;
- `map` преобразует каждый элемент и возвращает новый массив: `[1, 2].map { $0 * 2 }` → `[2, 4]`;
- `filter` оставляет элементы, удовлетворяющие условию;
- `reduce` сворачивает элементы в одно значение с начальным: `[1, 2, 3].reduce(0, +)` → `6`;
- `compactMap` преобразует элементы и отбрасывает `nil`: `["1", "a"].compactMap(Int.init)` → `[1]`;
- `flatMap` преобразует каждый элемент в последовательность и «разворачивает» результат в один плоский массив: `[[1, 2], [3]].flatMap { $0 }` → `[1, 2, 3]`.

Другие примеры: `sorted`, `first(where:)`, `contains(where:)`, `allSatisfy`, `min`/`max`, `zip`. Они не изменяют исходную коллекцию, дают декларативный код и хорошо комбинируются в цепочки. Для больших данных цепочки можно сделать ленивыми через `lazy`, чтобы не создавать промежуточные массивы.
