---
title: "На главном потоке есть ранлуп, есть ли какой-то такой аналог на других потоках?"
category: concurrency
order: 70
---

Да: у каждого потока есть свой объект run loop (`RunLoop.current`), система создаёт его при первом обращении. Но на вторичных потоках он не запускается автоматически: его нужно запустить явно, предварительно добавив хотя бы один источник ввода или таймер, иначе run loop сразу завершится.

Run loop на вторичном потоке нужен, если поток общается с другими потоками через порты или пользовательские источники, использует таймеры, вызывает `performSelector`-методы Cocoa или живёт долго и выполняет периодические задачи. Для разовой задачи без этого можно обойтись.
