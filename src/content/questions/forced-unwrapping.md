---
title: "Что такое принудительная распаковка (forced unwrapping)?"
category: swift
order: 111
---

Принудительная распаковка — оператор `!` после опционала: он извлекает значение, а если там `nil`, программа аварийно завершается с ошибкой времени выполнения (`Fatal error: Unexpectedly found nil while unwrapping an Optional value`). Фактически вы обещаете компилятору, что значения точно нет.

```swift
let value: Int? = 1
let a: Int = value!          // 1

let none: Int? = nil
let b = none!                // краш
```

Применяют, когда `nil` означает ошибку программиста (например, `URL(string: "https://apple.com")!` для заведомо корректной строки, или `IBOutlet`). В остальных случаях предпочитают безопасные способы: `if let`, `guard let`, `??` и optional chaining. Принудительное приведение типов `as!` работает так же: при несовпадении типов приложение падает.
