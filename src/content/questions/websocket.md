---
title: "Что такое WebSocket? Для чего он используется? В чём отличие от обычных HTTP-запросов?"
category: networking
order: 11
---

WebSocket — протокол, который поверх одного TCP-соединения даёт постоянный двусторонний канал между клиентом и сервером. Соединение устанавливается HTTP-запросом с заголовком `Upgrade: websocket` и затем остаётся открытым, а обе стороны могут отправлять сообщения в любой момент.

Отличие от HTTP: в HTTP клиент каждый раз инициирует запрос-ответ, и сервер не может сам передать данные. Чтобы получать обновления, приходится опрашивать сервер (polling). В WebSocket сервер присылает данные сам, без лишних заголовков и повторных соединений, поэтому меньше задержка и накладные расходы.

Применяют для чатов, биржевых котировок, онлайн-игр, совместного редактирования и других сценариев реального времени. В iOS для этого есть `URLSessionWebSocketTask` (iOS 13+):

```swift
let task = URLSession.shared.webSocketTask(with: url)
task.resume()
try await task.send(.string("hello"))
let message = try await task.receive()
```
