---
title: "Как нам сделать так, чтобы наша кастомная структура удовлетворяла протоколу Equatable"
category: swift
order: 60
---

Достаточно объявить соответствие `Equatable` в самом объявлении типа: если все хранимые свойства структуры соответствуют `Equatable`, компилятор синтезирует реализацию автоматически (для `enum` — если таковы все связанные значения).

```swift
struct Point: Equatable {
    var x: Int
    var y: Int
}
```

Если условия не выполнены, соответствие добавляется в extension или нужно своё поведение, реализуйте `==` как статический метод типа; `!=` стандартная библиотека предоставит сама. Оператор `==` должен быть эквивалентностью: рефлексивность (`a == a`), симметричность и транзитивность.

```swift
struct User: Equatable {
    var id: Int
    var cachedName: String

    static func == (lhs: User, rhs: User) -> Bool {
        lhs.id == rhs.id
    }
}
```
