---
title: "Что происходит с локальными объектами и замыканиями при нескольких await в одной функции?"
category: concurrency
order: 113
---

Компилятор трансформирует каждую `async`-функцию в **state machine** — конструкцию, похожую на генераторы (`yield`) в других языках. На каждый `await` вставляется точка приостановки, а переменные, которые нужны **после** этой точки, компилятор перемещает из стекового кадра в **heap-контекст** этой state machine.

Причина: между двумя точками `await` задача может «уснуть» и возобновиться на другом потоке, а сам стек вызова между этим временем может быть переиспользован или уничтожен — поэтому обычная стековая память не подходит для хранения состояния, которое должно пережить приостановку.

```swift
func doSomething() async {
    let config = Configuration() // 1
    await fetchData()            // 2 — приостановка
    print(config)                 // 3 — config сохранён в heap
}
```

`config` здесь будет храниться в heap, а не на стеке, потому что он нужен после `await`. Это увеличивает стоимость хранения и может привести к удержанию ресурсов, если неаккуратно обращаться с замыканиями и объектами.

Практическое следствие: если в `async`-функции с несколькими `await` создаются «тяжёлые» объекты (`Data`, `URLSession`, `ViewModel`), они могут жить дольше, чем ожидается — удерживать память, создавать retain cycle и даже приводить к утечкам, если их не освободить вручную.

Best practices:

- использовать функции вида `withXXX { }` (например, `withCheckedContinuation`, `withTaskGroup`), чтобы явно ограничить время жизни объектов рамками замыкания;
- вручную обнулять тяжёлые объекты, если они больше не нужны:

```swift
var cache: SomeHeavyCache? = SomeHeavyCache()
await doWork()
cache = nil // освобождаем явно, а не ждём выхода из функции
```

- избегать сильного захвата `self` в замыканиях внутри `async`-кода, особенно если `self` — `UIViewController`:

```swift
await withCheckedContinuation { [weak self] continuation in
    self?.doSomething { result in
        continuation.resume(returning: result)
    }
}
```
