---
title: "Как сделать не static dispatch у структуры?"
category: swift
order: 148
---

У структур нет наследования, поэтому их методы вызываются напрямую: статическая диспетчеризация (и возможен инлайнинг). Ни таблицы виртуальных методов, ни `dynamic` с Objective-C runtime для структур недоступны.

Динамическую (косвенную) диспетчеризацию можно получить через протоколы:

- **экзистенциальный тип `any P`**: вызов метода, объявленного в протоколе, идёт через protocol witness table контейнера, то есть косвенно;
- **дженерики без специализации**: `func f<T: P>(_ x: T)` в скомпилированном без оптимизаций или разделённом по модулям виде вызывает метод через witness table;
- **замыкания и функциональные значения**, которые хранит структура (`let action: () -> Void`): вызов косвенный;
- методы, объявленные только в `extension` протокола, вызываются статически, а объявленные в самом протоколе — динамически.

Итого: структура остаётся статически диспетчеризуемой, пока обращение идёт по её конкретному типу, а при работе через протокол или замыкание выбор реализации переносится на рантайм.
