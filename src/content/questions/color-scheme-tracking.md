title: "Как можно отследить изменение темы (светлая/тёмная) на устройстве во View? Что будет, если передать методу preferredColorScheme в качестве параметра nil?"
category: swiftui

Отследить смену темы можно через `@Environment(\.colorScheme)`: SwiftUI сам подписывает view на изменение этого значения и пересчитывает `body`, когда пользователь переключает тему в системе (или её принудительно меняют в приложении).

```swift
struct ThemedView: View {
    @Environment(\.colorScheme) private var colorScheme

    var body: some View {
        Text(colorScheme == .dark ? "Тёмная тема" : "Светлая тема")
    }
}
```

Модификатор `.preferredColorScheme(_:)` работает в обратную сторону — задаёт, какую тему должна использовать конкретная иерархия view, независимо от системной настройки:

```swift
ContentView()
    .preferredColorScheme(.dark) // принудительно тёмная тема для этой иерархии
```

Если передать `nil` — `preferredColorScheme(nil)` — принудительное переопределение **снимается**, и иерархия возвращается к теме, заданной выше по дереву (родительским `.preferredColorScheme`) или, если такого нет, к системной настройке устройства. Это удобно, например, чтобы сбросить локально заданную тему для отдельного экрана и снова начать следовать общей настройке приложения.
