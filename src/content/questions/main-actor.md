---
title: "Как с помощью Swift Concurrency ограничить выполнение функции на главном потоке?"
category: concurrency
order: 77
---

Пометить функцию атрибутом `@MainActor`: она будет выполняться только на главном акторе. Из кода на главном акторе её можно вызывать синхронно, из другого контекста — только через `await`, так как переход на главный актор является потенциальной точкой приостановки.

```swift
@MainActor
func show(_: Data) {
    // ... UI code to display the photo ...
}

func downloadAndShowPhoto(named name: String) async {
    let photo = await downloadPhoto(named: name)
    await show(photo)
}
```

Замыкание помечают так: `Task { @MainActor in show(photo) }`. Атрибут можно ставить и на структуру, класс или перечисление: тогда на главном акторе выполняются все их методы и доступ к свойствам. Главный актор тесно связан с главным потоком: код на главном акторе выполняется на главном потоке.
