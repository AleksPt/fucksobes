---
title: "В чём разница между assign и retain?"
category: memory
order: 60
---

Это атрибуты свойств в Objective-C, которые задают, как хранится значение.

- `retain` (в ARC ему соответствует `strong`) — свойство владеет объектом: при присваивании счётчик ссылок увеличивается, старое значение освобождается. Объект живёт, пока на него есть хотя бы одна сильная ссылка.
- `assign` — простое присваивание без владения и без изменения счётчика. Подходит для примитивов (`int`, `BOOL`, `CGFloat`). Для объектов это небезопасно: после освобождения объекта в свойстве остаётся «висячий» указатель, обращение к которому приведёт к падению.

Для ссылок на объекты без владения используют `weak` (обнуляется автоматически при освобождении объекта) или `unsafe_unretained`, аналог `assign` для объектов. В Swift им соответствуют `strong` (по умолчанию), `weak` и `unowned` (безопасный), `unowned(unsafe)` (аналог `assign`/`unsafe_unretained`).
