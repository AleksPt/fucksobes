---
title: "Для чего можно использовать User Defaults"
category: data-storage
order: 2
---

Для хранения несекретных настроек и конфигурации приложения: единиц измерения, предпочтений пользователя, флагов поведения. Значения — простые типы (`Int`, `Bool`, `String`, `URL`, `Date`, `Array`, `Dictionary`); другие объекты нужно предварительно архивировать в `Data`, но лучше выбирать простые типы. Значения по умолчанию регистрируют через `register(defaults:)`, а в SwiftUI с `UserDefaults` работает `@AppStorage`.
