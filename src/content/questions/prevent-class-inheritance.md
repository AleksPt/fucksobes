---
title: "Можно ли запретить наследование от класса"
category: swift
order: 39
---

Да: модификатор `final` перед `class` запрещает создавать подклассы. Применённый к свойству, методу или сабскрипту класса, он запрещает переопределять их в подклассах; попытка переопределить приводит к ошибке компиляции.

```swift
final class Base {}
// class Derived: Base {}  // ошибка: нельзя наследоваться от final-класса
```
