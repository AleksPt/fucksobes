---
title: "Что такое стек и куча?"
category: memory
order: 2
---

Стек используется для распределения статической памяти, а куча — для распределения динамической памяти, которая хранятся в оперативной памяти компьютера.

reference типы хранятся в куче, value типы хранятся в стеке

стек быстрее, чем куча

куча 1 на приложение, стек формируется для каждого потока
