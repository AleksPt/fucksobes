---
title: "Что такое async let? Чем отличается от обычной связки async/await?"
category: concurrency
order: 84
---

`async let` запускает дочернюю задачу параллельно с текущим кодом и сразу возвращает управление; результат берут позже через `await`. При обычной связке `let a = await f()` следующая строка выполняется только после завершения `f()`, то есть последовательно.

```swift
async let user = fetchUser()
async let posts = fetchPosts()
let (u, p) = try await (user, posts)  // обе загрузки шли одновременно
```

`async let` даёт параллелизм для заранее известного числа независимых операций. Это structured concurrency: дочерние задачи не могут пережить область видимости, а если выйти из неё до `await`, они неявно отменяются и ожидаются. Для переменного числа задач используют `TaskGroup`.
