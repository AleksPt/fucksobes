---
title: "В чём разница между классом и объектом класса?"
category: swift
order: 151
---

**Класс** — это описание, шаблон: он задаёт свойства, методы и инициализаторы. Сам по себе он не хранит данных конкретной сущности.

**Объект** (экземпляр, instance) — конкретная сущность, созданная по этому шаблону. У каждого объекта свои значения свойств, и он занимает память в куче.

```swift
class Dog {            // класс
    var name: String
    init(name: String) { self.name = name }
}

let a = Dog(name: "Рекс")   // два разных объекта
let b = Dog(name: "Бим")    // одного класса
```

Класс в Swift существует и в рантайме как метаданные (metadata) типа: в них хранятся таблица методов, суперкласс, размер экземпляра. Каждый объект содержит указатель на эти метаданные. Обращение к самому типу выполняется через `Dog.self`, а к статическим свойствам и методам (`static`, `class`) — без создания объекта.
