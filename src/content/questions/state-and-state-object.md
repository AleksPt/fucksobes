---
title: "Для чего нужны property wrappers State, StateObject?"
category: swiftui
order: 9
---

Для управления состоянием в интерфейсе пользователя.

**`@State`**

- Хранит состояние непосредственно в структуре View.
- Используется для простых значений и примитивных типов.
- SwiftUI автоматически обновляет отображение при изменении состояния.

**`@StateObject`**

- Инициализирует объект внутри View.
- Управляет состоянием объекта, который живёт столько же, сколько и сам View.
- Подходит для более сложных объектов, жизненный цикл которых не должен зависеть от изменений интерфейса.
