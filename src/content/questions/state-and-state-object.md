title: "Для чего нужны property wrappers State, StateObject?"
category: swiftui
order: 9
---

для управления состоянием в интерфейсе пользователя

**`@State`**

- Хранит состояние непосредственно в пределах структуры View.
- Используется для простых значений и примитивных типов.
- SwiftUI автоматически обновляет отображение при изменении состояния.

**`@StateObject`**

- для инициализации объекта внутри View
- Используется для управления состоянием объекта, который живёт столько же, сколько и сам View
- для более сложных объектов, которые должны соблюсти цикл жизни вне зависимости от изменений интерфейса
