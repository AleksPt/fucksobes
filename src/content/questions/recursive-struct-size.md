---
title: "Почему размер структуры должен быть известен заранее? Как починить struct Node с полем next: Node?"
category: swift
order: 146
---

Структура — value-тип, её поля хранятся прямо внутри значения. Чтобы выделить место (на стеке, в массиве, внутри другого типа), компилятор должен знать размер структуры на этапе компиляции.

```swift
struct Node {          // ошибка: value type 'Node' cannot have a stored property
    var payload = 0    // that recursively contains it
    var next: Node?
}
```

`Node` содержит `Node?`, который содержит ещё один `Node` и так далее, поэтому размер бесконечен. Способы исправления:

- сделать `Node` классом: поле `next` хранит только ссылку фиксированного размера (8 байт);
- использовать `indirect enum` (хранит связанные значения через указатель на кучу);
- вынести ссылку в коробку-класс `final class Box<T> { var value: T }` и хранить `var next: Box<Node>?`;
- хранить потомков в массиве `[Node]`: массив хранит буфер в куче, а в структуре лежит только ссылка.

Обычно для связных списков и деревьев берут класс: у них естественная ссылочная семантика.
