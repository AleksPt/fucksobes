---
title: "Что вызывает ошибку в коде, где складываются Int, Float и Double? Как исправить?"
category: swift
order: 115
---

```swift
let n1: Int = 1
let n2: Float = 2.0
let n3: Double = 3.34
var result = n1 + n2 + n3   // ошибка компиляции
```

Swift — строго типизированный язык и не выполняет неявных преобразований между числовыми типами: оператор `+` требует двух операндов одного типа, а здесь `Int`, `Float` и `Double`. Чтобы сложить числа, их нужно явно привести к одному типу, обычно к самому широкому:

```swift
let result = Double(n1) + Double(n2) + n3   // 6.34
```

Так проще заметить потерю точности (например, при переходе с `Double` на `Float` или `Int`) и нет скрытых ошибок из-за автоматических преобразований. Литералы гибче: `let x: Double = 1` сработает, потому что литерал `1` подстраивается под нужный тип.
