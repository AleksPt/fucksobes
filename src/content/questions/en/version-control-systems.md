---
title: "What is a version control system? Which ones do you know and which have you used?"
category: git
order: 5
---

A version control system (VCS) stores the history of changes to a project's files: who changed what, and when. It lets you return to any earlier version, compare changes, work on code in parallel in branches and merge the result, and track conflicts between several developers' edits.

Types:

- centralized (Subversion/SVN, Perforce): there is a single central server with the history, and clients talk to it;
- distributed (Git, Mercurial): every developer has a full copy of the repository with its history, so you can work and commit without a network.

The most widespread today is Git; repositories are hosted on GitHub, GitLab or Bitbucket. Every developer needs to know Git, while the other systems may turn up in older projects.
