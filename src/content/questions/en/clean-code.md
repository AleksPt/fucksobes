---
title: "What does clean code mean to you?"
category: architecture
order: 13
---

- **Clear names.** Use meaningful names for variables, functions, and classes.
- **Simplicity.** Avoid unnecessary complexity and write exactly as much as is needed.
- **Comments.** Document only complex or non-obvious places.
- **Following standards.** Follow common guidelines, such as the Swift API Design Guidelines.
- **Testability.** Write code that is easy to cover with tests.
- **No duplication.** Implement repeated functionality through reuse.
- **Clean dependencies.** Use dependency injection to reduce coupling.
- **Applying design principles.**
