---
title: "Advantages of SwiftUI over UIKit"
category: swiftui
order: 1
---

- Fast UI development: the interface is described declaratively, with less code than in imperative UIKit.
- Tight integration with Swift: `some View`, property wrappers, `ViewBuilder`, value types.
- Cross-platform: one codebase for iOS, iPadOS, macOS, tvOS, watchOS and visionOS.
- A rich set of transitions and animations out of the box: just change the state, and SwiftUI animates the difference itself.
- Previews in Xcode and gradual migration: SwiftUI can be mixed with UIKit.

Limitation: SwiftUI is available starting with iOS 13 / macOS 10.15, and some features appear only in newer OS versions.
