---
title: "What is polymorphism?"
category: architecture
order: 3
---

Polymorphism is the ability to work with objects of different types through one common interface: the calling code does not know the concrete type, and the implementation is determined by the object's actual type.

There is static polymorphism (overloading and generics, where the implementation is chosen at compile time) and dynamic, or subtype, polymorphism (method overriding and protocols, where it is chosen at runtime through dynamic dispatch).
