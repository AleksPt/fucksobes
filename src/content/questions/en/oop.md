title: "What is OOP?"
category: architecture
order: 1
---

**OOP** (object-oriented programming) is a paradigm based on objects: software entities that encapsulate data and functions. A program consists of objects that interact with each other.

The following features are usually named:

- **Encapsulation and data hiding**: an object's internal details are hidden from outside code (`private`, `public`).
- **Inheritance**: an object gets the properties of its parent; the alternative is composition.
- **Polymorphism**: code works with an interface and treats objects of different classes uniformly.
- **Dynamic dispatch**: the method is chosen at runtime rather than at compile time.
