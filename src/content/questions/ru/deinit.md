---
title: "Что такое деинициализатор (deinit)? Как его создать?"
category: swift
order: 126
---

Деинициализатор — специальный метод класса `deinit`, который вызывается автоматически непосредственно перед освобождением экземпляра (когда счётчик ссылок ARC достигает нуля). Его используют для очистки: отписаться от уведомлений и наблюдателей, остановить таймер, закрыть файл или соединение.

```swift
class Example {
    init() { print("создан") }
    deinit { print("удалён") }
}

var e: Example? = Example()
e = nil    // выведет «удалён»
```

Особенности: он есть только у классов (у структур и перечислений нет), не принимает параметры и не имеет скобок, вручную его вызвать нельзя. Деинициализатор суперкласса вызывается автоматически после деинициализатора подкласса. Память сама освобождать не нужно: ARC делает это за вас. Если `deinit` не вызывается при закрытии экрана или уничтожении объекта, это признак утечки, чаще всего retain cycle.
