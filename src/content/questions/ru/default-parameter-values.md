---
title: "Можно ли задать параметру функции значение по умолчанию?"
category: swift
order: 121
---

Да: значение указывают в объявлении параметра после знака `=`. При вызове такой аргумент можно опустить.

```swift
func eat(food: String = "spaghetti") {
    print("Yum! I ate some good \(food).")
}

eat()                  // spaghetti
eat(food: "pizza")     // pizza
```

Параметры со значениями по умолчанию принято ставить в конец списка: вызов остаётся читаемым, а аргументы, которые нужно передать, идут первыми. Благодаря именованным аргументам можно пропускать любые из необязательных параметров. Значения по умолчанию заменяют набор перегрузок с разным числом параметров. Они вычисляются при каждом вызове, а не один раз при объявлении.
