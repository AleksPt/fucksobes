---
title: "Что такое viewWithTag()?"
category: uikit
order: 134
---

У каждой `UIView` есть целочисленное свойство `tag` (по умолчанию 0). Метод `viewWithTag(_:)` ищет среди самой view и всех её вложенных subview (рекурсивно, в глубину) первую view с указанным тегом и возвращает её (или `nil`).

```swift
label.tag = 100
view.addSubview(label)
let found = view.viewWithTag(100) as? UILabel
```

Раньше так получали доступ к элементам, например к ячейкам, созданным из Interface Builder. Минусы: теги — «магические числа», легко получить конфликт значений, поиск по иерархии выполняется каждый раз, нет типобезопасности (нужно приведение), а при смене вёрстки код ломается. Тег 0 совпадает со значением по умолчанию, поэтому им пользоваться нельзя.

Вместо тегов лучше использовать `IBOutlet`, ссылки в свойствах, `accessibilityIdentifier` для UI-тестов или собственные типы view.
