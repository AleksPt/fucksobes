---
title: "Что такое функции первого класса? Поддерживает ли их Swift?"
category: swift
order: 137
---

Функции первого класса — функции, с которыми можно обращаться как с обычными значениями: присваивать переменным и константам, передавать аргументами, возвращать из других функций и хранить в коллекциях. Swift поддерживает это, хотя и не является чисто функциональным языком.

```swift
func double(_ x: Int) -> Int { x * 2 }

let f: (Int) -> Int = double            // присвоили функцию
[1, 2, 3].map(f)                        // передали как аргумент [2, 4, 6]

func makeAdder(_ n: Int) -> (Int) -> Int {
    { $0 + n }                          // вернули функцию
}
```

Тип функции записывается как `(Параметры) -> Результат`. На этом построены замыкания, функции высшего порядка (`map`, `filter`, `reduce`), completion handler и композиция функций.
