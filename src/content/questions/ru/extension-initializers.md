---
title: "Какие из инициализаторов мы можем добавить в extension?"
category: swift
order: 64
---

В extension можно добавлять новые инициализаторы к существующим типам, но с ограничениями для классов: расширение может добавить convenience-инициализаторы, а designated-инициализаторы и деинициализаторы должны быть в исходной реализации класса.

Для структур важны два момента.

- Инициализатор в extension не отключает автоматические инициализаторы (по умолчанию и memberwise); их отключает инициализатор, объявленный в теле структуры. Поэтому если в теле структуры своих инициализаторов нет, из extension можно вызвать `self.init(...)` с memberwise-инициализатором (а `self.init()` — если у всех свойств есть значения по умолчанию).
- Если структура объявлена в другом модуле, новый инициализатор до обращения к `self` обязан делегировать инициализатору из определяющего модуля.

```swift
extension Rect {
    init(center: Point, size: Size) {
        let origin = Point(x: center.x - size.width / 2,
                           y: center.y - size.height / 2)
        self.init(origin: origin, size: size)
    }
}
```
