---
title: "Inout. Если мы передаём value type через inout внутри метода то где он будет храниться на куче или на стеке"
category: memory
order: 14
---

Там же, где лежит исходная переменная: `inout` не копирует значение в отдельную область. Тип известен на этапе компиляции, поэтому его размер тоже известен, а параметр передаётся по адресу: локальная переменная остаётся на стеке, свойство экземпляра класса — в куче вместе с объектом.

Формально `inout` работает как copy-in copy-out, но для значения, лежащего по физическому адресу, оптимизация (call by reference) использует то же место в памяти. Временная копия нужна, например, для computed-свойства: вызываются его getter и setter.
