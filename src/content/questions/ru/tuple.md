---
title: "Что такое кортеж (tuple)?"
category: swift
order: 109
---

Кортеж объединяет несколько значений, возможно разных типов, в одно составное значение. Его часто используют, чтобы вернуть из функции сразу несколько результатов, не создавая отдельный тип.

Элементы могут быть безымянными (доступ по индексу) или именованными:

```swift
let pair = ("Midhun", 7)
pair.0                                  // "Midhun"

let person = (name: "Midhun", age: 7)
person.name                             // "Midhun"

func minMax(_ a: [Int]) -> (min: Int, max: Int)? { ... }
let (lo, hi) = (1, 5)                   // декомпозиция
```

Кортеж — value-тип и копируется при передаче. Его можно сравнивать оператором `==` (для кортежей до шести элементов, если элементы `Equatable`) и использовать в `switch` для сопоставления с образцом. Он не может соответствовать протоколам и иметь методы, поэтому для данных, которые живут долго, лучше завести структуру.
