---
title: "Как хранятся value и reference type в памяти"
category: memory
order: 6
---

Значение структуры хранится «по месту»: её поля лежат прямо в переменной, например в кадре стека функции. Присваивание создаёт независимую копию (value semantics).

Для класса в переменной на стеке лежит только ссылка, а сам экземпляр выделяется на куче. Помимо полей Swift добавляет служебные данные, в том числе счётчик ссылок (в примере WWDC16 экземпляр класса с двумя полями занимает четыре слова против двух у структуры). Присваивание копирует ссылку, и обе переменные указывают на один экземпляр (reference semantics).
