---
title: "Что такое globalActor и @MainActor? Для чего они используются?"
category: concurrency
order: 86
---

Глобальный актор — это актор-синглтон, который можно применять к типам и функциям с помощью атрибута: всё помеченное им исполняется изолированно на этом акторе. Объявляют его атрибутом `@globalActor` с `static let shared`:

```swift
@globalActor
actor DatabaseActor {
    static let shared = DatabaseActor()
}

@DatabaseActor
func save() { ... }
```

`@MainActor` — встроенный глобальный актор, который исполняет код на главном потоке. Им помечают функции, свойства, классы и протоколы, которые работают с UI (`UIViewController` и `View` уже изолированы на нём). Обращение к такому коду из другого контекста требует `await`. Чтобы выполнить вызов на главном акторе внутри асинхронной функции, используют `await MainActor.run { ... }`. Так компилятор проверяет, что доступ к общему состоянию идёт из правильного контекста, и предотвращает гонки данных.
