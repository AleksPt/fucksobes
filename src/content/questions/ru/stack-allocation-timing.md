---
title: "Когда происходит выделение памяти на стеке?"
category: memory
order: 74
---

Память на стеке выделяется **при входе в область видимости** — вызове функции, замыкания или блока кода — и освобождается автоматически при выходе из неё, без участия ARC.

Условие, при котором значение может попасть на стек: **размер должен быть известен на этапе компиляции**. Для каждого значения компилятор заранее знает, сколько байт занять на стеке, и просто сдвигает указатель вершины стека (stack pointer) на нужную величину — это очень дешёвая операция.

На стеке размещаются:

- локальные переменные примитивных и value-типов фиксированного размера (`Int`, `Bool`, простые `struct` без ссылочных полей переменного размера);
- параметры функций и адрес возврата;
- сама **структура кадра (stack frame)** для каждого вызова функции.

Как только выполнение покидает область (функция возвращается, замыкание завершается), stack pointer сдвигается обратно, и вся память кадра мгновенно освобождается — никакого подсчёта ссылок или сборки мусора не требуется.

```swift
func makePoint() -> CGPoint {
    let point = CGPoint(x: 1, y: 2) // выделяется на стеке при входе в makePoint
    return point                     // копируется по значению в кадр вызывающей функции
}                                     // стек-фрейм makePoint освобождается здесь
```

Если размер значения заранее неизвестен (например, `class`, или `struct`, хранящая переменную по размеру коллекцию), компилятор не может зарезервировать под него фиксированное место на стеке — такие значения (или их часть) уходят в кучу, а на стеке остаётся лишь указатель на них.
