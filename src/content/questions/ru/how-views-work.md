---
title: "Как view работают в SwiftUI?"
category: swiftui
order: 36
---

Три ключевых аспекта того, как SwiftUI видит view:

- **Identity (идентичность)** — как SwiftUI понимает, что view в разных обновлениях одно и то же или разные. В UIKit view — ссылочные типы, их идентифицирует указатель. В SwiftUI view — value-типы без указателей, поэтому идентичность определяется структурно (положением в иерархии, явным `id`), и от неё зависит, сохранится ли состояние и как анимируется изменение.
- **Lifetime (время жизни)** — как SwiftUI отслеживает существование view и данных во времени. Встретив `@State` или `@StateObject`, он сохраняет это хранилище, пока существует view с данной идентичностью: они связаны с её жизнью, а не с жизнью структуры.
- **Dependencies (зависимости)** — как SwiftUI понимает, когда и почему нужно обновить интерфейс. Зависимости — это входные данные view: свойства, `@Binding`, `@State`, объекты окружения и т. д. При их изменении пересчитывается `body`.

```swift
struct TestView: View {
    @Binding var isOn: Bool   // зависимость
    var name: String          // зависимость

    var body: some View {
        Toggle(name, isOn: $isOn)
    }
}
```
