title: "Что такое потокобезопасность?"

**Потокобезопасность (thread safety)** — свойство кода корректно работать при одновременном доступе из нескольких потоков, без порчи данных и непредсказуемого поведения.

Код потокобезопасен, если:

- к общим (shared) данным не может быть одновременного конкурентного доступа на чтение и запись без синхронизации;
- порядок выполнения потоков не влияет на итоговый результат;
- нет data race — ситуации, когда два потока одновременно обращаются к одной области памяти, и хотя бы один из них пишет.

**Способы добиться потокобезопасности:**

- сериализация доступа через `DispatchQueue` (serial queue) или `NSLock`/`NSRecursiveLock`;
- `DispatchSemaphore` для ограничения количества одновременных доступов;
- `actor` в Swift Concurrency — изолирует состояние и гарантирует последовательный доступ;
- immutable-данные (value types, `let`) — если данные не меняются, гонки за них не будет.

Сами по себе стандартные типы Swift (`Array`, `Dictionary` и т.д.) **не потокобезопасны** — их одновременное изменение из разных потоков без синхронизации приводит к data race.
