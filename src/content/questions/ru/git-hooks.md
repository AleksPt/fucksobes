---
title: "Что такое Git hook? Для чего они используются? Использовали ли вы их на практике?"
category: git
order: 10
---

Git hook — скрипт, который Git автоматически запускает при определённых событиях. Хуки лежат в `.git/hooks/` (файлы без расширения, например `pre-commit`) и могут быть написаны на любом языке; если скрипт возвращает ненулевой код, операция отменяется.

Часто используют:

- `pre-commit` — проверка перед коммитом: линтер (SwiftLint), форматирование, запрет отладочного кода;
- `commit-msg` — проверка формата сообщения (например, Conventional Commits);
- `pre-push` — запуск тестов перед отправкой;
- `post-merge`, `post-checkout` — обновление зависимостей после смены ветки.

Каталог `.git/hooks` не попадает в репозиторий, поэтому команде хуки раздают через настройку `core.hooksPath` на версионируемую папку или через инструменты вроде pre-commit и Husky. Обязательные проверки всё равно дублируют в CI, потому что хук можно обойти флагом `--no-verify`.
