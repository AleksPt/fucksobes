---
title: "Что такое UIScreen.main.bounds.width и как её используют для адаптивной вёрстки?"
category: swiftui
order: 54
---

`UIScreen.main` — статическое свойство класса `UIScreen`, возвращающее объект главного экрана устройства. `bounds` — это `CGRect`, описывающий размеры экрана в points (а не в физических пикселях — масштаб экрана, например Retina, уже учтён). `width` — ширина этого прямоугольника.

```swift
struct ContentView: View {
    var body: some View {
        Rectangle()
            .fill(Color.blue)
            .frame(width: UIScreen.main.bounds.width, height: 200)
    }
}
```

Используется, чтобы:

- растянуть элемент на всю ширину экрана (полноэкранные вью, фоновые изображения);
- подстроить размеры под ориентацию устройства (портретная/альбомная);
- унифицировать вид интерфейса на разных размерах экранов.

**Недостатки и почему стоит быть осторожным:**

- `UIScreen.main` не учитывает size class и реальный размер контейнера — на iPad с Split View или в multitasking-режиме на Mac ширина экрана и ширина view могут не совпадать.
- API относится к UIKit, а не к SwiftUI, поэтому в декларативном коде обычно предпочтительнее `GeometryReader` или модификатор `.containerRelativeFrame`, которые берут размер именно от родительского контейнера, а не от всего экрана.
