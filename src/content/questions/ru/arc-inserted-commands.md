---
title: "Какие команды ARC может вставлять в код?"
category: memory
order: 20
---

1. `retain` — увеличивает счётчик ссылок объекта.
2. `release` — уменьшает счётчик ссылок; если счётчик стал равен 0, освобождает объект.
3. `autorelease` — добавляет объект в autorelease pool, чтобы освободить его позже.
4. `store strong` — присваивает объект strong-свойству с соответствующим удержанием (`retain`).
5. `store weak` — присваивает объект weak-свойству без увеличения счётчика ссылок.
6. `load weak` — получает объект из weak-свойства, проверяя его на обнуление.
