---
title: "Гарантирует ли CoreData потокобезопасность?"
category: data-storage
order: 15
---

Нет: не все объекты Core Data потокобезопасны.

- Контекст (`NSManagedObjectContext`) и полученные из него `NSManagedObject` привязаны к очереди, в которой создан контекст. Работать с ними нужно через `perform` / `performAndWait`.
- Управляемые объекты нельзя передавать между очередями: это может привести к повреждению данных и падению приложения. Вместо объекта передают его `objectID` и в другом контексте получают объект по нему.
- Для фоновой работы используют контекст с приватной очередью, для UI — контекст главной очереди.
