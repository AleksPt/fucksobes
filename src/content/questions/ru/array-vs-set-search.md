---
title: "Что работает быстрее: проверка наличия элемента в Array или в Set? Какая сложность? За счет чего достигается ускорение в Set?"
category: algorithms
order: 3
---

Set работает быстрее, потому что использует хеш-таблицу: проверка наличия элемента выполняется за **O(1)** в среднем. В Array для этого нужно перебирать элементы — **O(n)**.
