---
title: "Расскажи про захват значений в замыкании. Зачем это делать, как и какие ключевые слова там могут использоваться?"
category: swift
order: 25
---

Замыкание может захватывать константы и переменные из окружающего контекста и использовать их, даже если исходная область видимости уже не существует. По умолчанию замыкание захватывает значения из внешней области сильными ссылками. Список захвата (capture list) позволяет управлять этим явно: он пишется в квадратных скобках перед списком параметров, а если он есть, обязательно и слово `in`.

Элементы списка инициализируются в момент создания замыкания: для каждого создаётся константа со значением одноимённой переменной из внешней области. Поэтому дальнейшие изменения внешней переменной замыкание не видит, а переменную без записи в списке видит актуальной:

```swift
var a = 0
var b = 0
let closure = { [a] in print(a, b) }
a = 10
b = 10
closure() // 0 10
```

Для классов элемент можно пометить `weak` или `unowned`, чтобы захватить слабую или бесхозную (unowned) ссылку, а не сильную. Это нужно, чтобы разорвать цикл сильных ссылок между объектом и замыканием (например, `[weak self]`, `[unowned self, weak delegate = self.delegate]`). `weak` подходит, когда захваченный объект может быть освобождён раньше (ссылка становится `nil`), `unowned` — когда время жизни то же или дольше; при обращении к уже освобождённому `unowned`-объекту происходит ошибка времени выполнения. Явный `[self]` означает сильный захват `self` с явным выражением намерения.
