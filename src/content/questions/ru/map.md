---
title: "Что такое map?"
category: swift
order: 27
---

`map(_:)` — метод `Sequence`, который возвращает массив результатов применения переданного замыкания к каждому элементу последовательности. Замыкание может вернуть значение того же или другого типа.

```swift
let cast = ["Vivien", "Marlon", "Kim", "Karl"]
let letterCounts = cast.map { $0.count }
// [6, 6, 3, 4]
```
