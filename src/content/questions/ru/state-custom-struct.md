---
title: "Можно ли в качестве типа данных для @State использовать собственную структуру? Будет ли View перерисовываться при изменении свойств такой структуры?"
category: swiftui
order: 45
---

Да, можно — `@State` рассчитан именно на value-типы, и собственная `struct` подходит для него даже лучше, чем класс.

View будет перерисовываться при изменении **любого** свойства такой структуры. Причина — value-семантика: структура хранится в хранилище `@State` целиком, и при мутации любого её свойства (`state.title = "..."`) создаётся новое значение структуры, которое целиком записывается обратно в хранилище. SwiftUI видит, что значение изменилось, и запускает пересчёт `body`.

```swift
struct FormState {
    var name: String = ""
    var isValid: Bool = false
}

struct FormView: View {
    @State private var form = FormState()

    var body: some View {
        TextField("Имя", text: $form.name) // меняет form.name → новое значение FormState
    }
}
```

Важно: изменение должно проходить через сам `@State`-объект (напрямую или через `Binding`, полученный из `$form`), а не через отдельную копию структуры, полученную, например, из массива без записи обратно, — иначе SwiftUI не узнает об изменении.
