---
title: "Что такое branch coverage?"
category: testing
order: 19
---

Branch coverage (покрытие ветвлений) показывает, какая часть ветвей условных конструкций была пройдена тестами: у каждого `if`, `guard`, `switch`, тернарного оператора есть ветки «условие выполнено» и «не выполнено», и метрика считает, сколько из них выполнено.

```swift
func discount(for age: Int) -> Int {
    if age >= 65 { return 20 }   // ветка 1
    return 0                     // ветка 2
}
```

Тест с `age = 70` даёт стопроцентное покрытие строк первой ветви, но пройдена лишь одна из двух веток (50 % branch coverage): случай `age < 65` не проверен. Поэтому branch coverage строже покрытия строк, ведь оно требует проверить оба исхода каждого условия. Xcode в основном показывает покрытие строк и функций, а данные по ветвям можно получить через `llvm-cov`.
