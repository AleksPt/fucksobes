---
title: "Почему нельзя вызвать memberwise initializer, если у структуры есть хотя бы одно private-свойство?"
category: swift
order: 106
---

Для структуры компилятор автоматически создаёт memberwise-инициализатор: он принимает по параметру на каждое хранимое свойство и присваивает их значения напрямую. Уровень доступа этого инициализатора не выше, чем у самого закрытого из свойств.

```swift
struct User {
    private let id: Int
}

let user = User(id: 1)   // ошибка: инициализатор недоступен из-за уровня защиты private
```

Если бы инициализатор оставался открытым, через него можно было бы задать значение `private`-свойства снаружи типа, что нарушило бы инкапсуляцию. Поэтому инициализатор тоже становится `private` (то есть виден только внутри типа и его расширений в том же файле), а в других местах его вызвать нельзя.

Решение — написать свой инициализатор: он может быть `internal` или `public` и сам задавать закрытые значения. Свойство с `private var` и значением по умолчанию в memberwise-инициализатор не попадает.
