---
title: "Чем отличается цикл for от forEach?"
category: swift
order: 100
---

Оба обходят элементы последовательности, но различаются возможностями:

- В `for … in` доступны `break`, `continue` и `return` из окружающей функции, а также ранний выход из цикла. Внутри него можно использовать `try` и `await` без ограничений, а компилятор оптимизирует его как обычный цикл.
- `forEach` — метод, принимающий замыкание. `return` внутри выходит только из текущей итерации (как `continue`), а прервать весь обход нельзя. Он удобен в цепочках вызовов и для функций-ссылок: `items.forEach(print)`.

```swift
for x in [1, 2, 3] { if x == 2 { break }; print(x) }   // 1
[1, 2, 3].forEach { if $0 == 2 { return }; print($0) } // 1, 3
```

`forEach` не даёт особого преимущества по скорости; с `async` замыканиями он тоже не подходит: `forEach` не дождётся их выполнения (в отличие от `for await`). Поэтому для обычных обходов предпочитают `for … in`.
