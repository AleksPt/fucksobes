---
title: "Как найти общие элементы двух массивов? Какая асимптотика?"
category: algorithms
order: 29
---

Самый простой способ — превратить массивы во множества и взять пересечение:

```swift
let a = [1, 3, 5, 7, 9]
let b = [0, 3, 4, 7, 8]
let common = Set(a).intersection(b)   // [3, 7], порядок не определён
```

Сложность: создание `Set` из `Array` — `O(n)`, пересечение — в среднем `O(min(n, m))` (для каждого элемента меньшего множества проверка `contains` за `O(1)`), итого `O(n + m)`. Дополнительная память — `O(n)`. Хеш-таблица делает поиск быстрым, но элементы должны быть `Hashable`, а порядок и дубликаты теряются.

Альтернативы:

- два вложенных цикла — `O(n·m)`, без доп. памяти, годится только для маленьких массивов;
- сортировка обоих массивов и два указателя — `O(n log n + m log m)`, доп. память `O(1)`, сохраняет порядок и учитывает дубликаты;
- если нужно сохранить порядок первого массива: `a.filter(Set(b).contains)`.
