---
title: "Что такое вычисляемые свойства (computed properties)?"
category: swift
order: 120
---

Вычисляемое свойство не хранит значение, а вычисляет его при обращении с помощью `get`, а при необходимости позволяет записать значение через `set`. Оно объявляется только как `var` и с явным типом.

```swift
class Weight {
    var kilograms: Float = 0.0
    var pounds: Float {
        get { kilograms * 2.205 }
        set { kilograms = newValue / 2.205 }   // newValue — неявное имя параметра
    }
}

let w = Weight()
w.kilograms = 100
print(w.pounds)      // 220.5
w.pounds = 315
print(w.kilograms)   // 142.85715
```

Если есть только `get`, свойство доступно только для чтения, и слово `get` можно опустить (записать тело сразу). Вычисляемые свойства доступны в классах, структурах, перечислениях и расширениях (в отличие от хранимых). Значение пересчитывается при каждом обращении, поэтому тяжёлые вычисления лучше кэшировать в `lazy`-свойстве, а данные, которые нужно хранить, в хранимом свойстве с наблюдателями `willSet` и `didSet`.
