---
title: "Что означает public private(set)? Чем fileprivate, private и internal отличаются друг от друга?"
category: swift
order: 135
---

Уровни доступа:

- `private` — сущность видна только внутри своего объявления и его расширений в том же файле;
- `fileprivate` — видна во всём файле;
- `internal` (по умолчанию) — видна во всём модуле, но не снаружи;
- `public` — видна в других модулях;
- `open` — как `public`, плюс можно наследоваться и переопределять члены классов вне модуля.

Для свойств можно задать отдельный уровень для записи: `public private(set) var` означает, что читать значение можно снаружи модуля, а изменять только внутри типа (и его расширений в файле).

```swift
public struct Counter {
    public private(set) var value = 0
    public mutating func increment() { value += 1 }
}
```

Так обеспечивают инкапсуляцию: владелец контролирует изменения состояния, а внешний код может только читать. Уровень записи не может быть выше уровня чтения.
