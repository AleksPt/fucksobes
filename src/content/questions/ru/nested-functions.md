---
title: "Что такое вложенная функция?"
category: swift
order: 122
---

Вложенная функция — это функция, объявленная внутри другой функции. Снаружи она не видна и доступна только в теле объемлющей функции, поэтому ею удобно выделять вспомогательные шаги, не засоряя область видимости типа или файла.

```swift
func makeCounter() -> () -> Int {
    var count = 0
    func increment() -> Int {     // вложенная функция
        count += 1
        return count
    }
    return increment
}

let next = makeCounter()
next()   // 1
next()   // 2
```

Вложенная функция может захватывать константы и переменные объемлющей функции, как замыкание, и продолжать использовать их, даже когда внешняя функция уже завершилась (в примере выше `count` живёт, пока жив `next`). Её можно возвращать и передавать как значение.
