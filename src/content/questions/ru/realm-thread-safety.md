---
title: "Потокобезопасен ли Realm?"
category: data-storage
order: 33
---

И да, и нет — модель потокобезопасности у Realm особая.

- Сам **файл базы** Realm потокобезопасен: несколько потоков могут читать и писать в него одновременно, Realm сериализует запись через внутренние транзакции.
- Но **объекты Realm** (`Object`, `Results`, сам `Realm`) — **не** потокобезопасны и не могут передаваться между потоками напрямую. У каждого потока (или `DispatchQueue`) должен быть свой инстанс `Realm`, открытый на этом потоке.

Если попытаться передать объект Realm в замыкание, выполняющееся на другом потоке, приложение упадёт с рантайм-ошибкой.

Правильный способ передать данные между потоками — передать не сам объект, а его `primaryKey` (или `ThreadSafeReference`), и на целевом потоке заново получить объект из своего инстанса `Realm`:

```swift
let ref = ThreadSafeReference(to: dog)

DispatchQueue.global().async {
    let realm = try! Realm()
    guard let dog = realm.resolve(ref) else { return } // объект мог быть удалён
    // работа с dog в контексте своего потока
}
```
