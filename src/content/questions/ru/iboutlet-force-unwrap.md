---
title: "Почему в IBOutlet используется force unwrap"
category: swift
order: 19
---

Outlet объявляют как неявно извлекаемый опционал (`UILabel!`). Такие опционалы применяются, когда из структуры программы ясно, что значение после первой установки будет всегда; тогда его не нужно проверять и извлекать при каждом обращении. Основное применение — этап инициализации класса. Не следует использовать их, если переменная может позже снова стать `nil`.

У view контроллера иная схема: она загружается лениво (`loadView()` вызывается, когда свойство `view` запрошено, а оно ещё `nil`), а `viewDidLoad()` вызывается после загрузки иерархии view в память, в том числе из nib. То есть outlet заполняется не в инициализаторе, а позже, и после этого его значение предполагается всегда существующим.

```swift
class ViewController: UIViewController {
    @IBOutlet var titleLabel: UILabel!

    override func viewDidLoad() {
        super.viewDidLoad()
        titleLabel.text = "Привет"
    }
}
```
