---
title: "В чём разница между if let и guard let?"
category: swift
order: 93
---

Оба безопасно разворачивают опционал, но различаются областью видимости распакованного значения и стилем кода:

- `if let` создаёт значение только внутри своего блока: снаружи оно недоступно, а ветка `else` необязательна.
- `guard let` делает значение доступным после себя в оставшейся части области; блок `else` обязательный и должен выйти из области (`return`, `throw`, `continue` и т. д.).

```swift
if let name = user.name {
    print(name)            // name виден только здесь
}

guard let name = user.name else { return }
print(name)                // name виден и дальше
```

`if let` подходит, когда нужно просто выполнить действие при наличии значения. `guard let` подходит для проверки предусловий: основной код остаётся на одном уровне вложенности, а обработка «неудачного» случая идёт сразу в начале.
