`async` помечает функцию, которая может приостановиться и продолжить выполнение позже; `await` отмечает каждую возможную точку приостановки при её вызове. Приостановка никогда не бывает неявной или вытесняющей: код может приостановиться только там, где вызывается другая асинхронная функция.

```swift
let photoNames = await listPhotos(inGallery: "Summer Vacation")
let photo = await downloadPhoto(named: photoNames[0])
show(photo)
```

Пока код ждёт на `await`, остальной код программы продолжает работать. После возобновления Swift не гарантирует, на каком потоке продолжится функция.
