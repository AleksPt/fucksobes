---
title: "Что такое Task в Swift Concurrency?"
category: concurrency
order: 91
---

`Task` — единица асинхронной работы: в ней выполняется `async`-код. Через `Task` можно запустить асинхронную функцию из синхронного контекста.

```swift
Task {
    let user = try await api.loadUser()
    await MainActor.run { label.text = user.name }
}
```

Свойства задачи:

- запускается сразу после создания, вызывать `start` не нужно;
- имеет приоритет и наследует контекст создателя (актор, приоритет, значения task-local);
- может быть отменена (`task.cancel()`); отмена кооперативная: код должен сам проверять `Task.isCancelled` или вызывать `try Task.checkCancellation()`;
- возвращает результат через `await task.value` (или `task.result`);
- бывает неструктурированной (`Task { }`, `Task.detached { }`) и структурированной (дочерние задачи через `async let` и `TaskGroup`, которые не могут пережить родителя).

Задача не привязана к конкретному потоку: после `await` она может продолжиться на другом потоке.
