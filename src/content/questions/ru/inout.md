---
title: "Модификатор `inout`"
category: swift
order: 43
---

Параметры функции по умолчанию являются константами. Параметр с модификатором `inout` (пишется перед типом) получает значение при вызове, изменяется внутри функции и возвращается обратно, заменяя исходное значение, так что изменения сохраняются после вызова.

В качестве аргумента можно передать только переменную (не константу и не литерал), перед ней ставится `&`. У `inout`-параметров не может быть значений по умолчанию, а вариативные параметры нельзя пометить как `inout`.

```swift
func swapTwoInts(_ a: inout Int, _ b: inout Int) {
    let temporaryA = a
    a = b
    b = temporaryA
}

var someInt = 3
var anotherInt = 107
swapTwoInts(&someInt, &anotherInt)
// someInt == 107, anotherInt == 3
```
