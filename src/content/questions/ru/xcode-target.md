---
title: "Что такое Target в Xcode?"
category: tooling
order: 41
---

**Target** (цель сборки) — точно определяет, какой продукт будет собран из проекта, и содержит инструкции для его сборки: какие исходные файлы и ресурсы входят в продукт, какие у него собственные настройки сборки (build settings) и какие шаги (build phases) нужно выполнить.

Основные фазы сборки (**Build Phases**) таргета выполняются по порядку и обычно включают:

- **Compile Sources** — компиляция исходного кода, входящего в таргет;
- **Link Binary With Libraries** — линковка с фреймворками и библиотеками;
- **Copy Bundle Resources** — копирование ресурсов (изображений, xib, plist) в итоговый бандл;
- пользовательские **Run Script** фазы — например, запуск SwiftLint или генерация кода перед компиляцией.

Один проект может содержать несколько таргетов, использующих один и тот же исходный код, но собирающих разные продукты: например, основное приложение, его виджет-расширение и отдельный таргет для unit-тестов — у каждого свой набор файлов, зависимостей и build settings, хотя все они лежат в одном `.xcodeproj`.

```
MyApp.xcodeproj
├── Target: MyApp          — основное приложение
├── Target: MyAppWidget     — расширение-виджет
└── Target: MyAppTests      — unit-тесты
```
