---
title: "Что такое неявная распаковка (implicitly unwrapped optional)?"
category: swift
order: 112
---

Неявно распаковываемый опционал объявляют с `!` вместо `?` (`var name: String!`). Это обычный опционал, значение которого компилятор автоматически распаковывает при обращении. Если там окажется `nil`, программа упадёт, как при принудительной распаковке.

```swift
var name: String! = "Virat"
let student: String = name   // распаковывается автоматически
name = nil
let player: String = name    // краш: значения нет
let other = name             // без указания типа получится обычный String?, краша нет
```

Если тип не указан явно, значение сохраняется как обычный опционал, а распаковывается только там, где без этого нельзя.

Применяют, когда значение точно появится сразу после инициализации, но не в самом инициализаторе: например, `@IBOutlet` (заполняются при загрузке view) или свойства, которые задаются сразу после создания объекта и больше не станут `nil`. Если значение может исчезнуть, используют обычный опционал.
