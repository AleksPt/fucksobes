---
title: "Является функция main самым ранним этапом, когда мы можем выполнить наш код?"
category: uikit
order: 72
---

Нет. Некоторый код выполняется раньше вызова `UIApplicationMain`: Apple прямо упоминает методы, которые система вызывает автоматически до `main`, например `load()`. Тяжёлый код в них замедляет запуск, поэтому работу до `UIApplicationMain` рекомендуется минимизировать.

Кроме того, система может выполнить prewarming: создать процесс и загрузить библиотеки, на которые ссылается приложение, после чего процесс приостанавливается без выполнения кода приложения.
