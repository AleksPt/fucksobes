---
title: "Что такое автозамыкание (autoclosure) в Swift? Как и когда его использовать?"
category: swift
order: 125
---

`@autoclosure` автоматически оборачивает переданное выражение в замыкание без параметров, поэтому при вызове функции не нужны фигурные скобки. Выражение при этом не вычисляется, пока функция сама не вызовет замыкание, то есть вычисление отложено и может не произойти вообще.

```swift
func log(_ message: @autoclosure () -> String, enabled: Bool) {
    if enabled { print(message()) }
}

log("Ответ: \(expensiveCalculation())", enabled: false)   // expensiveCalculation не вызовется
```

Так устроены `assert(_:_:)`, операторы `&&`, `||` и `??`: правый операнд вычисляется только при необходимости. Применяют для ленивого вычисления дорогих аргументов и для более чистого синтаксиса. Если замыкание нужно сохранить, добавляют `@escaping`. Не стоит злоупотреблять: из-за отложенного вычисления и «невидимых» скобок вызов может запутать читателя, поэтому в документации Swift отмечено: функции с автозамыканиями принято вызывать, но не принято реализовывать без необходимости.
