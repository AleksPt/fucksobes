---
title: "Что такое JSON? Для чего он используется?"
category: networking
order: 6
---

JSON (JavaScript Object Notation) — текстовый формат обмена данными. Он строится из объектов `{ "ключ": значение }`, массивов `[...]` и простых значений: строк, чисел, `true`/`false` и `null`.

```json
{ "name": "Mark", "age": 30, "tags": ["ios", "swift"] }
```

JSON читаем человеком, компактен, не зависит от языка и поддерживается практически везде, поэтому это самый распространённый формат передачи данных между клиентом и сервером. Также его используют для конфигурационных файлов и локального хранения небольших данных. В Swift его разбирают и формируют с помощью `Codable`.
