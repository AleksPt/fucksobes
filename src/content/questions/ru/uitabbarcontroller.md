---
title: "Что такое UITabBarController? Для чего используется и как реализован?"
category: uikit
order: 83
---

`UITabBarController` — контейнерный контроллер с панелью вкладок (`UITabBar`): каждая вкладка соответствует своему view controller'у, и пользователь переключается между ними нажатием на элемент панели. Так организуют основные независимые разделы приложения (лента, поиск, профиль).

В классическом API контроллеры задаются свойством `viewControllers`, а иконка и название вкладки берутся из `tabBarItem` каждого контроллера. Обычно каждая вкладка — свой `UINavigationController`, то есть у разделов отдельные навигационные стеки. Контроллер вкладки загружается лениво, при первом открытии, а состояние вкладки сохраняется при переключении.

Панель удобна для 2–5 разделов; при большем количестве лишние вкладки уходят в пункт «More». Начиная с iOS 18 доступен новый API на основе `UITab` и `UITabGroup`, а на iPad панель может отображаться сверху и превращаться в боковую панель (sidebar).
