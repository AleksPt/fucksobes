---
title: "Чем отличаются systemLayoutSizeFitting и sizeThatFits?"
category: uikit
order: 97
---

Оба метода возвращают размер view, но считают его по-разному.

- `systemLayoutSizeFitting(_:)` запускает движок Auto Layout: он решает констрейнты внутри view и возвращает размер, который подходит под них для заданного целевого размера. Для минимального размера передают `UIView.layoutFittingCompressedSize`, для максимального — `layoutFittingExpandedSize`; есть перегрузка с приоритетами по осям. Метод не требует переопределения.
- `sizeThatFits(_:)` — метод ручного расчёта: он возвращает размер, который view предпочла бы иметь при заданных ограничениях, и по умолчанию просто возвращает текущий `bounds.size`. Его переопределяют в view, где раскладка идёт вручную (`layoutSubviews`), и он не использует констрейнты.

`UILabel`, `UIButton` и другие стандартные элементы реализуют `sizeThatFits`, поэтому для них он даёт размер по контенту. Для view на Auto Layout используют `systemLayoutSizeFitting`, например, чтобы высчитать высоту ячейки.
