title: "Ключевые слова inout и mutating"

`inout` передаёт переменную в функцию так, что изменения внутри видны вызывающему после возврата.

Формально это copy-in copy-out (call by value result): при вызове значение копируется, в теле изменяется копия, при возврате она присваивается оригиналу. Поэтому для computed-свойства или свойства с observers при вызове срабатывает getter, а при возврате — setter. Оптимизация: если аргумент хранится по физическому адресу в памяти, внутри и снаружи функции используется одна и та же память (call by reference). Код нужно писать так, чтобы он работал и без этой оптимизации.

`mutating` ставится перед `func` в методе структуры или перечисления. По умолчанию методы значимых типов не могут менять их свойства; `mutating` разрешает это (в том числе присвоить `self` новый экземпляр). Механически это тот же `inout`: в mutating-методе `self` передаётся как `inout` (в SIL метод принимает `@inout Point`). Поэтому такой метод нельзя вызвать на константе (`let`): константу нельзя передать как `inout`.

```swift
func swapTwoInts(_ a: inout Int, _ b: inout Int) {
    (a, b) = (b, a)
}

struct Point {
    var x = 0.0, y = 0.0
    mutating func moveBy(x dx: Double, y dy: Double) {
        x += dx
        y += dy
    }
}
```
