---
title: "ForEach(array, id: \\.self) падает с ошибкой о повторяющихся id, хотя по бизнес-требованиям строки должны повторяться. Как решить проблему?"
category: swiftui
order: 47
---

SwiftUI требует, чтобы `id` каждого элемента `ForEach` был уникальным (иначе не может корректно сопоставить старые и новые элементы при обновлении и построить diff). `id: \.self` использует само значение строки как идентификатор, поэтому как только в массиве появляются два одинаковых значения, идентификаторы совпадают. Обычно это не краш: SwiftUI пишет в консоль предупреждение (`the ID ... occurs multiple times within the collection, this will give undefined results!`) и ведёт себя непредсказуемо, например переиспользует состояние и анимации не тех строк.

Раз повторяющиеся значения — не баг, а ожидаемое поведение, id должен различать элементы **не по содержимому**, а по их **позиции/происхождению**, а не быть равным самому значению.

Варианты решения:

- **Обернуть в структуру с собственным уникальным id**, где строка — лишь одно из свойств:

```swift
struct Row: Identifiable {
    let id = UUID()
    let title: String
}

let rows = array.map { Row(title: $0) }

ForEach(rows) { row in
    Text(row.title)
}
```

- **Индекс как часть идентификатора**, если порядок стабилен и элементы не переставляются и не удаляются посреди списка:

```swift
ForEach(Array(array.enumerated()), id: \.offset) { index, title in
    Text(title)
}
```
Этот способ проще, но менее безопасен для анимаций и переупорядочивания — при удалении элемента из середины SwiftUI может «перепривязать» состояние не к тому элементу, так как индексы у оставшихся строк сдвинутся.

Массив `rows` нужно хранить в модели или `@State`, а не создавать в `body`: иначе `UUID()` генерируется заново при каждом перерасчёте, и идентичность теряется.

Первый вариант (обёртка с `UUID`) предпочтительнее: он даёт стабильную идентичность, не зависящую ни от содержимого, ни от позиции в массиве, и корректно работает с анимациями вставки/удаления.
