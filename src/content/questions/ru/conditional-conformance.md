---
title: "Что такое conditional conformance? Как его реализовать и для чего используют?"
category: swift
order: 103
---

Conditional conformance — условное соответствие протоколу: дженерик-тип подписывается на протокол только тогда, когда его параметры удовлетворяют заданным требованиям. Записывают его в `extension` с `where`.

```swift
extension Array: Equatable where Element: Equatable {}   // массив сравним, если его элементы сравнимы

struct Box<T> { let value: T }
extension Box: Codable where T: Codable {}
```

`[Int]` получает `Equatable`, а массив функций — нет. Так стандартная библиотека даёт `Array`, `Optional`, `Dictionary` и другим типам `Equatable`, `Hashable`, `Codable` без ручной реализации. Начиная со Swift 4.1 условное соответствие поддерживается на уровне языка.

Применяют, чтобы типы-обёртки автоматически повторяли возможности вложенных типов, не требуя лишних ограничений на сам дженерик. Ограничения: нельзя подписать один и тот же тип на протокол несколькими пересекающимися расширениями, а в рантайме приведение `as? Protocol` учитывает условия.
