---
title: "Что такое опциональная цепочка (optional chaining)?"
category: swift
order: 110
---

Optional chaining — способ обратиться к свойству, методу или сабскрипту опционала, который может быть `nil`. Если в цепочке `?.` встретился `nil`, остальная часть цепочки не выполняется, а всё выражение равно `nil`. Если значение есть, вызов выполняется как обычно.

```swift
let city = person?.address?.city        // String?
person?.address?.updateZip("101000")   // выполнится только если person и address не nil
if let count = list?.items.count { print(count) }
```

Тип результата всегда опциональный, даже если сам член не опциональный (например, `Int?` вместо `Int`), а несколько уровней вложенности не создают вложенных опционалов. Так можно безопасно идти по цепочке связанных объектов без вложенных `if let`, а вместе с `??` задавать значение по умолчанию. Это безопасная альтернатива принудительной распаковке.
