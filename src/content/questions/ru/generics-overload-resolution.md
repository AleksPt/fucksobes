Перегрузка выбирается на этапе компиляции по статически известным типам аргументов и ограничениям, а не по типу значения в рантайме. Из подходящих кандидатов побеждает более специализированный: например, перегрузка для конкретного `Int` предпочтительнее `func f<T>(_:)`, а `func h<T: P>(_:)` — предпочтительнее `func h<T>(_:)`.

Внутри другого обобщённого контекста о `T` известно только то, что объявлено в его ограничениях, поэтому выбирается перегрузка, подходящая для этих ограничений:

```swift
func f<T>(_ x: T) { print("generic") }
func f(_ x: Int) { print("Int") }
func g<T>(_ x: T) { f(x) }

f(1) // Int
g(1) // generic — внутри g тип T для компилятора неизвестен
```
