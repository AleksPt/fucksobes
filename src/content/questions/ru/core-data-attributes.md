---
title: "Что такое Attributes в Core Data?"
category: data-storage
order: 30
---

**Attribute** (атрибут) — свойство сущности, которое хранит конкретное значение, а не ссылку на другой объект. Это аналог столбца таблицы в реляционной базе: каждый атрибут сущности описывает один тип данных, который будет храниться у каждого её экземпляра.

Основные типы атрибутов:

- `String`, `Integer 16/32/64`, `Double`, `Float`, `Decimal`, `Boolean`;
- `Date`, `Binary Data`, `UUID`, `URI`;
- `Transformable` — для произвольных объектов, не входящих в стандартный набор (например, `UIColor`), через `NSSecureUnarchiveFromDataTransformer`.

У атрибута задают:

- **опциональность** — может ли значение отсутствовать (`Optional`), эквивалент `NOT NULL` в SQL;
- **значение по умолчанию** (`Default Value`) — что подставится, если явно не задать значение при создании объекта;
- ограничения (например, максимальная длина строки) — для проверки при валидации перед сохранением.

```swift
final class User: NSManagedObject {
    @NSManaged var name: String       // атрибут типа String
    @NSManaged var age: Int16         // атрибут типа Integer 16
    @NSManaged var createdAt: Date?   // опциональный атрибут типа Date
}
```

В отличие от **связи (relationship)**, атрибут всегда хранит значение самого объекта, а не указывает на другую запись Core Data.
