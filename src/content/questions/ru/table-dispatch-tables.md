---
title: "Что хранят в себе таблицы в table dispatch?"
category: swift
order: 77
---

В таблицах хранятся указатели на **реализации методов**, а не на сами классы.

- У класса есть таблица виртуальных функций (vtable): для каждого метода, включая унаследованные, в ней лежит адрес реализации для этого класса.
- Если метод переопределён в подклассе, запись в vtable подкласса указывает на переопределённую реализацию.
- Для протоколов используется witness table: для каждого соответствия типа протоколу в ней лежат реализации требований протокола.
