---
title: "Чем отличается функция от метода?"
category: swift
order: 89
---

Функция — самостоятельный блок кода, объявленный глобально или внутри другой функции; она не привязана к типу. Метод — функция, объявленная внутри типа (класса, структуры, перечисления или протокола), которая работает с его экземпляром или самим типом.

```swift
func greet(_ name: String) { print("Hi, \(name)") }   // функция

struct User {
    var name: String
    func greet() { print("Hi, \(name)") }              // метод: имеет доступ к self
}
```

Методы экземпляра получают неявный параметр `self` и имеют доступ к свойствам и другим методам типа. Есть также методы типа (`static` и `class`), которые вызываются на самом типе. Методы структур и перечислений, изменяющие состояние, помечаются `mutating`. Технически метод — это функция с привязкой к типу, а различаются они в основном областью видимости и контекстом вызова.
