---
title: "Почему у классов нет memberwise-инициализатора, как у структур?"
category: swift
order: 107
---

Для классов Swift автоматически создаёт только инициализатор без параметров `init()` и только если у всех хранимых свойств есть значения по умолчанию. Memberwise-инициализатора для классов нет по нескольким причинам:

- **Наследование.** У класса может быть суперкласс со своими свойствами, которые нужно инициализировать первыми (двухфазная инициализация). Автоматический инициализатор, который затрагивал бы и свойства предка, был бы неоднозначным и хрупким: добавление свойства в суперкласс изменило бы сигнатуру всех подклассов.
- **Ссылочная семантика.** Экземпляры классов обычно связаны с идентичностью и сложной настройкой (ресурсы, зависимости), а не с простым набором значений. Структуры чаще просто агрегируют данные, для которых такой инициализатор удобен.
- **Контроль доступа.** Автоматически сгенерированный инициализатор зависел бы от уровней доступа свойств, и класс мог бы получить непредсказуемый интерфейс.

Для структуры memberwise-инициализатор пропадает, если внутри самой структуры объявить любой свой `init`. Сохранить его можно, объявив свой инициализатор в `extension`. У классов приходится писать инициализаторы вручную.
