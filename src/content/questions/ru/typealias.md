---
title: "Что такое typealias в Swift?"
category: swift
order: 47
---

Псевдоним для существующего типа данных. Новый тип не создаётся: компилятор считает псевдоним и исходный тип одним и тем же.

```swift
typealias Dollar = Double
typealias Weight = Float

let totalCosts: Dollar = 10.5
let mass: Weight = 150.0 + 70.0
```

Используют, чтобы:

- дать сложному типу короткое понятное имя: `typealias Handler = (Result<Data, Error>) -> Void`;
- выразить смысл значения (`typealias UserID = Int`), не создавая новый тип;
- сократить длинные составные типы: кортежи, замыкания, композиции протоколов (`typealias Codable = Encodable & Decodable`);
- вводить псевдонимы для замены типа в одном месте (например, при смене `Float` на `Double`).

Псевдоним не даёт дополнительной безопасности типов: `UserID` и `Int` взаимозаменяемы, а для строгого различия нужна отдельная структура.
