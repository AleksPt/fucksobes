---
title: "Что такое Memory Layout?"
category: memory
order: 11
---

Способ организации и размещения данных в памяти для конкретного объекта, структуры или класса. Всё это происходит автоматически.

Memory layout описывает:

1. **Размер (size)** — сколько байтов занимает объект в памяти.
2. **Выравнивание (alignment)** — минимальный шаг, с которого должен начинаться объект в памяти.
3. **Смещение (offset)** — позиция каждого свойства относительно начала объекта.

Получить эти значения для типа можно через `MemoryLayout<T>`:

- `size` — сколько байт занимает значение;
- `alignment` — требование к выравниванию адреса (обычно степень двойки);
- `stride` — шаг от начала одного элемента до начала следующего в массиве: `size`, округлённый до кратного `alignment`.

```swift
struct S { var a: Int8; var b: Int64 }
MemoryLayout<S>.size       // 16
MemoryLayout<S>.alignment  // 8
MemoryLayout<S>.stride     // 16
```

Порядок свойств влияет на размер из-за выравнивания: между `Int8` и `Int64` появляются байты-заполнители. Для класса `size` равен размеру ссылки (8 байт на 64-битной платформе), независимо от числа свойств.
