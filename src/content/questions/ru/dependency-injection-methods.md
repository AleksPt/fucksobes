---
title: "Какие способы инъекции зависимости есть"
category: architecture
order: 22
---

1. **Constructor Injection** (через инициализатор) — наиболее распространённый и безопасный способ: зависимость передаётся при создании объекта и не может быть изменена.
2. **Property Injection** (через свойства) — зависимость устанавливается через свойство после создания объекта. Менее безопасен, так как свойство может остаться неустановленным.
3. **Method Injection** (через методы) — зависимость передаётся через метод, который её использует, например `configure`.
4. **Protocol Injection** (через протоколы)
5. **Service Locator** (через локатор служб)
6. **Environment Variables Injection** (через переменные окружения)
7. **Factory Injection** (через фабрики объектов)

Для упрощения управления зависимостями можно использовать DI-фреймворки, например **Swinject**.
