---
title: "Может ли функция быть результирующим значением другой функции?"
category: swift
order: 152
---

Да. В Swift функции — значения первого класса, поэтому функцию можно вернуть из другой функции; у возвращаемой функции могут быть любые параметры.

```swift
func makeAdder(_ n: Int) -> (Int) -> Int {
    return { $0 + n }
}

let addFive = makeAdder(5)
addFive(3) // 8
```

Возвращаемая функция может захватывать значения из внешней (см. замыкания), поэтому так делают фабрики поведения, каррирование и функции высшего порядка. Если возвращаемое замыкание сохраняется где-то и переживает вызов, оно считается escaping, но для возвращаемого значения это указывать не нужно — тип `(Int) -> Int` уже подразумевает такое поведение.
