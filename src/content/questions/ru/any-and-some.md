---
title: "Зачем нужны ключевые слова `any` и `some`"
category: swift
order: 70
---

Оба ключевых слова скрывают конкретный тип значения за протоколом, но по-разному.

`some` (opaque type) означает один конкретный тип, идентичность которого скрыта от вызывающего кода: компилятор его знает, клиенты модуля — нет. При этом реализация функции сама выбирает возвращаемый тип, тогда как в обобщённой функции тип выбирает вызывающий.

`any` (boxed protocol type, он же existential type) означает значение любого типа, соответствующего протоколу; конкретный тип становится известен только во время выполнения и может меняться. Поэтому `any` гибче: в `[any Shape]` можно хранить элементы разных типов, а в `[some Shape]` — только одного скрытого типа. Взамен `some` даёт более сильные гарантии: например, сохраняет доступность операций, зависящих от точного типа (вроде `==`), а значение типа `any Shape` само не соответствует протоколу `Shape`.

```swift
func makeShape() -> some Shape { Triangle(size: 3) }

var shapes: [any Shape] = [Triangle(size: 3), Square(size: 2)]
```
