---
title: "Что такое RunLoop? Сколько ранлупов запущено в приложении по умолчанию?"
category: concurrency
order: 69
---

Run loop — цикл обработки событий, который держит поток занятым, пока есть работа, и усыпляет его, когда работы нет. `RunLoop` обрабатывает события источников ввода (`Port`, события оконной системы) и таймеры.

У каждого потока, включая главный, есть связанный объект run loop: система создаёт его по мере необходимости. Автоматически запускается только run loop главного потока (при старте приложения), поэтому по умолчанию работает один run loop. Вторичные потоки должны запускать свой run loop явно.
