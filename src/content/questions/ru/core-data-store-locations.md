---
title: "Где могут храниться данные из Core Data?"
category: data-storage
order: 20
---

Место хранения определяется типом `NSPersistentStore`, который подключён к координатору:

- `NSSQLiteStoreType` — файл SQLite на диске (по умолчанию и чаще всего); данные сохраняются между запусками;
- `NSBinaryStoreType` — двоичный файл; загружается в память целиком;
- `NSInMemoryStoreType` — только в оперативной памяти, после закрытия приложения данные пропадают; удобно в тестах;
- `NSXMLStoreType` — XML-файл (только macOS).

Файл SQLite по умолчанию лежит в каталоге `Application Support` внутри песочницы приложения. Можно указать свой путь, включая общий контейнер App Group, чтобы делиться данными с расширениями. Через `NSPersistentCloudKitContainer` данные дополнительно синхронизируются с iCloud.
