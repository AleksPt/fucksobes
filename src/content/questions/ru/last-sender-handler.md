Последним объектом, который может обработать нажатие, является **`UIApplication`** или его делегат (**`AppDelegate`**), но только когда у кнопки `target = nil`.

Нажатие кнопки — это не касание, идущее по responder chain, а action: `UIControl` отправляет его через `UIApplication.sendAction(_:to:from:for:)`. Если у кнопки задан `target`, метод вызывается прямо на нём, и цепочка не нужна.

**Цепочка респондеров при `target = nil`**

Поиск начинается с first responder (если его нет, то с самой кнопки) и идёт вверх по цепочке до первого объекта, реализующего метод:

1. **View** — сама view и её superview, затем выше по иерархии view.
2. **`UIViewController`** — если view является корневым view контроллера.
3. **`UIWindow`** — окно, которому принадлежит иерархия.
4. **`UIApplication`**.
5. **`AppDelegate`** — только если он наследует `UIResponder`.

Если метод не найден нигде, нажатие ничего не делает.
