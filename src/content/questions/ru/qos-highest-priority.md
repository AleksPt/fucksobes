---
title: "Какой у нас есть самый высокий приоритет в QoS?"
category: concurrency
order: 23
---

Самый высокий — **User-interactive**. Все уровни по убыванию приоритета:

- **User-interactive** — максимальный приоритет для задач, которые должны завершиться до обновления UI (например, анимации).
- **User-initiated** — высокий приоритет для задач, инициированных пользователем, которые должны завершиться быстро (например, запросы пользователя).
- **Utility** — средний приоритет для задач, которые могут занимать некоторое время, но не блокируют интерфейс (например, загрузка данных).
- **Background** — низкий приоритет для фоновых задач, не влияющих на пользовательский опыт (например, синхронизация данных).
