---
title: "Что такое вариативный (variadic) параметр?"
category: swift
order: 132
---

Вариативный параметр принимает ноль или больше значений одного типа. Его объявляют с тремя точками после типа, а внутри функции он доступен как массив.

```swift
func sum(_ numbers: Int...) -> Int {
    numbers.reduce(0, +)      // numbers: [Int]
}

sum()              // 0
sum(1, 2, 3)       // 6
```

Особенности:

- вызывают функцию, перечисляя значения через запятую; передать готовый массив напрямую нельзя (его придётся «развернуть» вручную или перегрузить функцию);
- в одной функции может быть несколько вариативных параметров (с Swift 5.4), если после каждого следует параметр с меткой;
- пример из стандартной библиотеки — `print(_:separator:terminator:)`.
