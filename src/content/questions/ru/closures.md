Замыкание (closure) — самодостаточный блок кода, который можно передавать и использовать в программе; аналог lambda и blocks в других языках. Замыкание может захватывать и хранить ссылки на константы и переменные из контекста, в котором оно определено (closing over); всю связанную работу с памятью Swift берёт на себя.

Замыкания бывают трёх видов: глобальные функции, вложенные функции и closure expressions (безымянные замыкания). Замыкания — ссылочные типы: присваивая замыкание переменной, вы записываете в неё ссылку на него.

```swift
let sorted = [3, 1, 2].sorted { $0 < $1 }
```
