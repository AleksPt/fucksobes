---
title: "Для чего нужен .gitignore?"
category: git
order: 9
---

`.gitignore` — файл со списком шаблонов путей, которые Git не отслеживает и не добавляет в репозиторий. Обычно в него включают сгенерированные и локальные файлы, которые не нужны другим разработчикам: артефакты сборки (`build/`, `DerivedData/`), пользовательские настройки Xcode (`xcuserdata/`), `.DS_Store`, папки зависимостей (`Pods/`, `.build/`), а также файлы с секретами и локальными конфигурациями.

Файл кладут в корень репозитория (можно и в подпапки), а его правила действуют только на ещё не отслеживаемые файлы: если файл уже в репозитории, его нужно убрать из индекса командой `git rm --cached <файл>`. Шаблоны для Swift и Xcode есть на gitignore.io и в репозитории GitHub `gitignore`. Личные правила, которые не надо делиться с командой, можно добавить в `.git/info/exclude` или глобальный игнор-файл.
