---
title: "Как оптимизировать размер памяти, занимаемой структурой (alignment)?"
category: memory
order: 67
---

Поля структуры размещаются в порядке объявления, и каждое выравнивается по своему `alignment`: между полями появляются байты-заполнители (padding). Swift не переупорядочивает поля сам, поэтому порядок влияет на размер.

```swift
struct A { var a: Int8; var b: Int64; var c: Int8 }   // size 17, stride 24
struct B { var b: Int64; var a: Int8; var c: Int8 }   // size 10, stride 16
```

В `A` после `Int8` идёт 7 байт заполнителя до `Int64`, а в конце ещё 7 до кратности alignment. В `B` крупное поле идёт первым, мелкие подряд, и padding остаётся только в хвосте.

Как уменьшить размер:

- располагать поля по убыванию `alignment` (сначала `Int64`/`Double`/ссылки, потом `Int32`, `Int16`, `Int8`/`Bool`);
- использовать типы подходящей разрядности (`Int32` вместо `Int64`, когда диапазона хватает);
- заменять несколько `Bool` перечислением или набором флагов `OptionSet`;
- проверять результат через `MemoryLayout<T>.size`, `.stride` и `.alignment`.

Учитывать нужно именно `stride`: он определяет, сколько места занимает элемент в массиве. Оптимизацию имеет смысл делать для типов, которых в памяти миллионы.
