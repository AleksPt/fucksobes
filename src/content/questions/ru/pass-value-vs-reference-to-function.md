---
title: "Что произойдёт, если передать в функцию объект reference-типа и объект value-типа?"
category: swift
order: 147
---

**Value-тип** (структура, перечисление, кортеж): функция получает независимую копию (семантически; на деле компилятор и copy-on-write часто избегают реального копирования). Параметры по умолчанию неизменяемы, а изменения копии не влияют на оригинал. Чтобы изменить исходное значение, используют `inout`.

**Reference-тип** (класс): копируется ссылка на тот же экземпляр. Функция работает с общим объектом, поэтому изменения его свойств видны снаружи. Присвоить параметру другую ссылку она не может (параметры константы), а сам объект остаётся единым.

```swift
struct P { var x = 0 }
final class C { var x = 0 }

func change(_ p: P, _ c: C) {
    var p = p; p.x = 1      // оригинал не изменится
    c.x = 1                 // оригинал изменится
}
```

По умолчанию Swift передаёт аргументы без лишнего retain/release (параметры «одолжены» вызывающим), поэтому передача ссылок дёшева. Если структура содержит ссылочные поля (массив, строка, класс), копирование увеличивает счётчик ссылок каждого из них.
