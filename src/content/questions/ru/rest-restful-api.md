---
title: "Что такое REST? Что такое RESTful API?"
category: networking
order: 5
---

REST (Representational State Transfer) — архитектурный стиль клиент-серверных приложений, в котором сервер предоставляет ресурсы, а клиент работает с ними через единообразный интерфейс, чаще всего поверх HTTP. Каждый ресурс имеет свой адрес (URL), а действия выражаются HTTP-методами: `GET` читает, `POST` создаёт, `PUT` и `PATCH` изменяют, `DELETE` удаляет.

Ключевые ограничения REST:

- клиент и сервер независимы друг от друга;
- сервер не хранит состояние клиента между запросами (stateless): каждый запрос содержит всё необходимое;
- ответы можно кэшировать;
- интерфейс единообразен: ресурсы, их представления (обычно JSON) и стандартные методы и коды ответов.

RESTful API — это API, которое следует этим принципам: например, `GET /users/42` возвращает пользователя, а `DELETE /users/42` удаляет его.
