---
title: "Что такое DispatchWorkItem?"
category: concurrency
order: 102
---

`DispatchWorkItem` — объект-обёртка над блоком кода, который можно отправить в очередь GCD. В отличие от обычного замыкания, им можно управлять после постановки в очередь.

```swift
let item = DispatchWorkItem(qos: .userInitiated) {
    print("работа")
}
item.notify(queue: .main) { print("готово") }

DispatchQueue.global().async(execute: item)
item.wait()   // блокирующее ожидание завершения
item.cancel() // отмена
```

Что даёт `DispatchWorkItem`:

- **Отмена** (`cancel()`): если задача ещё не начала выполняться, она не запустится; выполняющуюся задачу это не прерывает, внутри блока нужно самому проверять `isCancelled`.
- **Ожидание** (`wait()`) и **уведомление о завершении** (`notify(queue:execute:)`).
- **Свой QoS и флаги** (например, `.barrier`) для конкретной задачи.
- Один и тот же объект можно выполнить несколько раз (`perform()` или повторной отправкой в очередь), пока он не отменён.

Типичное применение — debounce (отменить предыдущую отложенную задачу и поставить новую) и отмена запланированной через `asyncAfter` работы.
