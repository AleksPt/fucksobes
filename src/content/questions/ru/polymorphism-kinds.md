---
title: "Какие бывают виды полиморфизма? Compile-time и run-time polymorphism"
category: architecture
order: 52
---

Полиморфизм — способность работать с разными типами через единый интерфейс. По моменту выбора реализации различают два вида.

**Compile-time (статический, ранняя привязка)** — реализация выбирается на этапе компиляции:

- **перегрузка функций и операторов** (`func f(_: Int)`, `func f(_: String)`);
- **параметрический полиморфизм — дженерики** (`func swapValues<T>(...)`); компилятор часто специализирует код под конкретный тип;
- вызов методов структур и `final`-методов.

**Run-time (динамический, поздняя привязка)** — реализация выбирается во время выполнения по реальному типу объекта:

- **переопределение методов** в подклассах (вызов через vtable);
- **протоколы**: значение типа `any Protocol` вызывает метод через witness table;
- вызовы через Objective-C runtime (`@objc dynamic`).

```swift
class Animal { func voice() { print("...") } }
class Dog: Animal { override func voice() { print("Woof") } }
let a: Animal = Dog()
a.voice()        // "Woof": выбор реализации во время выполнения
```

Статический полиморфизм быстрее и лучше оптимизируется, динамический — гибче и позволяет подменять реализацию без перекомпиляции клиента.
