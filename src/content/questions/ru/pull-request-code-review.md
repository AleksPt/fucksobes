---
title: "Что такое Pull/Merge Request? Зачем их используют? Что такое Code Review?"
category: git
order: 8
---

Pull Request (в GitLab — Merge Request) — запрос на слияние ветки в целевую (обычно `main` или `develop`) на платформе хостинга репозитория. В нём видно набор изменений (diff), описание, обсуждения и результаты автоматических проверок CI. Изменения попадают в основную ветку только после того, как запрос одобрен и проверки прошли.

Code Review — проверка чужих изменений другим разработчиком перед слиянием. Ревьюер ищет ошибки и проблемы с производительностью и безопасностью, оценивает читаемость, архитектуру и соответствие принятым соглашениям, оставляет комментарии и просит доработки.

Зачем: повышается качество кода, знания о проекте распространяются по команде, единый стиль легче поддерживать, а ошибки находят до попадания в основную ветку. Обычно для этого настраивают защиту веток (обязательное ревью и зелёный CI).
