---
title: "Что такое перегрузка функций (overloading)?"
category: swift
order: 144
---

Перегрузка — несколько функций с одним именем, которые различаются сигнатурой: числом параметров, их типами, внешними метками аргументов или типом возвращаемого значения.

```swift
func show(_ x: Int) { print("Int \(x)") }
func show(_ x: String) { print("String \(x)") }
func show(_ x: Int, times: Int) { }     // другое число параметров
func value() -> Int { 1 }
func value() -> String { "1" }          // перегрузка по возвращаемому типу: тип выводится из контекста
let s: String = value()
```

Компилятор выбирает нужную перегрузку на этапе компиляции по типам аргументов и контексту; из подходящих выбирается наиболее специфичная (конкретный тип предпочтительнее дженерика, а перегрузка без преобразований — с преобразованиями). Если однозначно выбрать нельзя, получится ошибка «ambiguous use».

Отличаться только именем параметра (внутренним) или только `inout` нельзя. Перегрузка сильно расходится с динамической диспетчеризацией: выбор перегрузки статический, поэтому при вызове через базовый тип выбирается версия для этого типа, а не для реального класса объекта. Чрезмерная перегрузка операторов и функций замедляет компиляцию и ухудшает читаемость.
