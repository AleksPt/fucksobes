---
title: "Зачем нужно ключевое слово indirect?"
category: swift
order: 48
---

Для создания рекурсивных перечислений: когда связанное значение случая имеет тип самого перечисления.

```swift
enum Example {
    case something(Int, Example)   // ошибка: рекурсивное перечисление без indirect
}

indirect enum Expression {
    case number(Int)
    case addition(Expression, Expression)
    case multiplication(Expression, Expression)
}
```

Перечисление — value-тип, и компилятор должен знать его размер, а у рекурсивного размер получился бы бесконечным. `indirect` заставляет хранить связанные значения косвенно, через указатель на кучу, поэтому размер становится конечным. Ключевое слово можно поставить перед отдельным случаем (`indirect case …`) или перед всем перечислением. Применяют для деревьев, связных списков и выражений.
