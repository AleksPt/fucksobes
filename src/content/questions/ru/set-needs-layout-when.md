---
title: "Когда наступит layout для setNeedsLayout?"
category: uikit
order: 40
---

`setNeedsLayout()` лишь помечает layout view как недействительный и сразу возвращается: пересчёт произойдёт в следующем цикле обновления (update cycle), а не в момент вызова. Благодаря этому можно инвалидировать layout у нескольких view и обработать всё за один цикл, что обычно лучше для производительности. Вызывать метод нужно на главном потоке.

Если layout нужен немедленно, используйте `layoutIfNeeded()`: он выполняет layout поддерева сразу, если есть отложенные обновления, а если их нет — ничего не делает.
