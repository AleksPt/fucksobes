---
title: "Что такое lazy var? Для чего она используется?"
category: swift
order: 98
---

`lazy var` — хранимое свойство, начальное значение которого вычисляется не при создании экземпляра, а при первом обращении к нему. После этого значение сохраняется и повторно не вычисляется.

```swift
class Report {
    lazy var data: [Int] = loadHugeData()   // загрузится только при первом обращении
}
```

Применяют, когда инициализация дорогая (загрузка данных, тяжёлые объекты) или зависит от других свойств экземпляра (в замыкании можно обращаться к `self`). Ограничения: только `var` (значение вычисляется после инициализации), не потокобезопасна (одновременное первое обращение из разных потоков может выполнить инициализацию дважды) и не работает как вычисляемое свойство: значение не пересчитывается. В структурах доступ к ней требует `mutating`, поскольку меняет экземпляр.
