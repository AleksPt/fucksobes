title: "Что такое dependency manager? Для чего они используются? Какие приходилось использовать?"

Dependency manager (менеджер зависимостей) автоматизирует подключение сторонних библиотек: скачивает нужные версии, разрешает зависимости между ними, интегрирует в проект и обновляет по правилам версий (semver). Не приходится копировать код вручную, а версии фиксируются и воспроизводятся у всей команды.

В iOS используют три основных:

- **Swift Package Manager (SPM)** — встроенный в Xcode и Swift, сегодня основной вариант;
- **CocoaPods** — самый старый и распространённый, файл `Podfile`, создаёт workspace и подключает зависимости через отдельный проект `Pods`;
- **Carthage** — собирает зависимости в готовые фреймворки (XCFramework), которые подключаются вручную; файл `Cartfile`.

Иногда зависимости подключают вручную, копируют исходники в проект или используют готовые XCFramework (бинарные зависимости). Для воспроизводимости версии фиксируют в lock-файлах (`Package.resolved`, `Podfile.lock`, `Cartfile.resolved`).
