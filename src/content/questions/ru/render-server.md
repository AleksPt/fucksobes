---
title: "Что такое render server?"
category: uikit
order: 139
---

Render server — системный процесс (на iOS часть `backboardd`), который отвечает за композитинг и отрисовку интерфейса всех приложений на экран, а также за выполнение анимаций Core Animation. Приложение не рисует прямо на дисплей: оно готовит дерево слоёв и отправляет его в render server, где GPU собирает итоговый кадр.

Схема:

1. **В процессе приложения:** обработка событий, раскладка (`layoutSubviews`), подготовка содержимого слоёв (`draw(_:)`, декодирование изображений), затем commit транзакции.
2. **В render server:** получение дерева слоёв, выполнение анимаций, композитинг на GPU и вывод кадра в такт обновлению экрана.

Отсюда важные следствия: анимации Core Animation продолжают играть, даже если главный поток приложения занят (они уже переданы в render server), а лишняя работа GPU (offscreen rendering, blending, большие текстуры) замедляет именно render server. Кадр должен быть готов вовремя как в приложении, так и в render server.
