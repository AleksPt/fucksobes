---
title: "Способы разворачивания опционала (+ compactMap в массивах)"
category: swift
order: 17
---

Опционал либо содержит значение, либо `nil`. При обращении к нему нужно обработать оба случая; способы:

- **Optional binding** (`if let`, `guard let`, `while let`): проверяет наличие значения и делает его доступным как временную константу или переменную. Допустима краткая запись `if let value { ... }`. Константы из `if let` видны только внутри тела `if`, а из `guard` — в коде после него.
- **Nil-coalescing** (`??`): подставляет значение по умолчанию, если слева `nil`.
- **Force unwrapping** (`!`): извлекает значение и останавливает выполнение, если там `nil`; применяется, когда `nil` означает неустранимую ошибку.
- **Optional chaining** (`?.`): вызов свойства или метода на опционале; при `nil` цепочка возвращает `nil`.

Для массивов `compactMap(_:)` применяет замыкание, возвращающее опционал, и собирает в массив только результаты, не равные `nil`:

```swift
let possibleNumbers = ["1", "2", "three", "///4///", "5"]

let mapped: [Int?] = possibleNumbers.map { str in Int(str) }
// [1, 2, nil, nil, 5]

let compactMapped: [Int] = possibleNumbers.compactMap { str in Int(str) }
// [1, 2, 5]
```
