---
title: "Какие модификаторы реагируют на события жизненного цикла View?"
category: swiftui
order: 40
---

В SwiftUI три основных модификатора:

- `onAppear(perform:)` — выполняет действие, когда представление появилось на экране; вызывается при каждом появлении, а не только при первом;
- `onDisappear(perform:)` — выполняет действие, когда представление исчезло;
- `task(priority:_:)` — запускает асинхронное действие (`async`) при появлении и автоматически отменяет его, когда представление исчезает.

```swift
List(items) { item in Text(item.name) }
    .onAppear { analytics.track("screen_opened") }
    .task { items = await api.loadItems() }        // отменится при уходе с экрана
    .onDisappear { analytics.track("screen_closed") }
```

Главное отличие `task` от `onAppear`: работа в `onAppear` не отменяется при уходе с экрана (для асинхронного кода пришлось бы создавать `Task` вручную и хранить его для отмены), а `task` запускается и останавливается вместе с представлением. Вариант `task(id:)` перезапускает задачу, когда значение `id` меняется. Дополнительно есть `onChange(of:)` для реакции на изменение значения и `scenePhase` для состояния всей сцены.
