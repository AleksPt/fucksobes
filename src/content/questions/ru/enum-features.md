---
title: "Назовите особенности enum в Swift"
category: swift
order: 91
---

`enum` в Swift — полноценный тип, а не просто набор констант:

- **значение перечисления** — тип с ограниченным набором вариантов (`case`), при этом компилятор проверяет полноту `switch`;
- **связанные значения (associated values)** — каждый вариант может нести данные разных типов: `case success(Data)`, `case failure(Error)`;
- **исходные значения (raw values)** — все варианты имеют значения одного типа (`Int`, `String`); для `String` и `Int` они могут выводиться автоматически, а создать enum из raw value можно через `init?(rawValue:)`;
- **свойства и методы**: вычисляемые свойства, методы, инициализаторы, статические члены и расширения, соответствие протоколам;
- **value-тип**: копируется при передаче, изменяющие методы помечаются `mutating`;
- **`CaseIterable`** даёт коллекцию `allCases`;
- **`indirect`** позволяет делать рекурсивные перечисления.

Enum не может иметь хранимых свойств экземпляра: только вычисляемые и статические. Это удобная основа для состояний, результатов операций и конечных автоматов.
