---
title: "Что такое defer?"
category: swift
order: 113
---

`defer` откладывает выполнение блока кода до момента выхода из текущей области видимости: тела функции, цикла, `do` или `if`, независимо от способа выхода — `return`, `throw`, `break` или обычного завершения. Обычно его используют для освобождения ресурсов рядом с их получением: закрыть файл, снять блокировку, завершить транзакцию.

```swift
func read() throws {
    let file = try open()
    defer { close(file) }      // выполнится при любом выходе из функции
    try process(file)
}
```

Если в области несколько `defer`, они выполняются в обратном порядке (LIFO): последний объявленный — первым. Пример из статьи, где `defer` печатают 1, 2, 3, 4, 5, 6, даёт вывод `6 5 4 3 2 1`, а `defer` во вложенном блоке `if` срабатывает при выходе из этого блока, поэтому раньше остальных. Внутри `defer` нельзя выходить из блока (`return`, `break`, `throw`).
