---
title: "Что такое Thread Sanitizer?"
category: tooling
order: 22
---

Thread Sanitizer (TSan) — инструмент времени выполнения в Xcode, который ищет гонки данных (data race) и другие ошибки синхронизации. Гонка происходит, когда два потока обращаются к одной памяти одновременно, хотя бы один пишет, и нет синхронизации.

Он инструментирует код при компиляции и следит за каждым обращением к памяти и порядком синхронизации между потоками; когда находит нарушение, то останавливает выполнение и сообщает в Issue Navigator, какие два обращения конфликтуют и где они были. Включается в схеме запуска: **Edit Scheme → Run → Diagnostics → Thread Sanitizer** (в тестах — то же для схемы Test).

Ограничения: замедляет программу в несколько раз и увеличивает потребление памяти, работает в симуляторе, но не на реальном устройстве, и не может работать одновременно с Address Sanitizer. Он обнаруживает гонки только в тех местах, которые реально выполнились при запуске. Проблемы с обращением к UI не из главного потока ловит другой инструмент, Main Thread Checker.
