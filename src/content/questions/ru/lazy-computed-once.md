---
title: "Могут ли ленивые (lazy) свойства вычисляться больше одного раза?"
category: swift
order: 105
---

Нет. Значение `lazy var` вычисляется при первом обращении, сохраняется в свойстве, и при следующих обращениях возвращается уже сохранённое, а код инициализации не выполняется повторно.

```swift
class Sample {
    var a = 10, b = 2
    lazy var sum: Int = { print("вычисляю"); return a + b }()
}

let s = Sample()
s.sum          // «вычисляю», 12
s.a = 20
s.sum          // 12: пересчёта нет
```

Поэтому `lazy` не подходит для значения, которое должно следовать за изменением других свойств: для этого используют вычисляемое свойство. Пересчитать `lazy`-значение можно, только присвоив ему новое значение вручную: оно `var`. Оговорка: без синхронизации первое обращение из нескольких потоков одновременно может выполнить инициализацию не один раз, потому что `lazy` не потокобезопасен.
