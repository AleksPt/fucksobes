---
title: "Что такое виртуальные функции?"
category: architecture
order: 64
---

Виртуальная функция — метод, реализация которого выбирается во время выполнения по реальному типу объекта, а не по типу переменной. Это основа динамического полиморфизма: вызов метода через ссылку на базовый класс выполняет переопределённую версию подкласса.

В C++ такие методы помечают `virtual`. В Swift все методы классов виртуальные по умолчанию (если не `final`, не `private` без переопределений и не `static`): вызов идёт через таблицу виртуальных методов (vtable), где для каждого класса хранятся указатели на реализации.

```swift
class Shape { func draw() { print("shape") } }
class Circle: Shape { override func draw() { print("circle") } }
let s: Shape = Circle()
s.draw()    // "circle": метод выбран по реальному типу
```

Цена: вызов идёт через дополнительный указатель и мешает инлайнингу, поэтому `final`, структуры и `private` позволяют компилятору вызвать метод напрямую (статическая диспетчеризация). Для протоколов аналог vtable — protocol witness table.
