---
title: "Что такое data race?"
category: concurrency
order: 89
---

Data race (гонка данных) возникает, когда два потока одновременно обращаются к одной и той же области памяти, хотя бы один из них выполняет запись и между обращениями нет синхронизации. Результат такой операции не определён: можно получить испорченные данные, неверные значения или падение.

```swift
var counter = 0
DispatchQueue.concurrentPerform(iterations: 1000) { _ in
    counter += 1          // чтение и запись из разных потоков без синхронизации
}
// counter почти наверняка будет меньше 1000
```

Отличие от race condition: data race — конкретная проблема доступа к памяти, а race condition — ошибка логики, когда результат зависит от порядка выполнения. Гонка данных может её вызвать, но race condition бывает и без data race (например, при правильно синхронизированных, но неверно упорядоченных проверках).

Защита: последовательные очереди, `NSLock` и другие блокировки, барьеры, атомарные операции, изоляция акторами, value-типы вместо общих ссылочных. Обнаруживают гонки Thread Sanitizer и проверки Sendable в Swift 6.
