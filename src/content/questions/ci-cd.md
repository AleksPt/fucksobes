**CI/CD** (continuous integration and delivery) — практика разработки, которая помогает поддерживать код и доставлять приложения тестировщикам и пользователям. GitHub Actions описывает её как платформу для автоматизации сборки, тестов и деплоя.

Пример из экосистемы Apple: **Xcode Cloud** автоматически и часто собирает проект, запускает тесты и проверки и раздаёт сборки тестировщикам через TestFlight; после проверки версию можно выпустить в App Store. В GitHub Actions процессы описываются как workflow в YAML-файлах в `.github/workflows/`, а выполняются на runner'ах (Linux, Windows, macOS или self-hosted).
