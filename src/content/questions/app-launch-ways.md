---
title: "Как можно запустить приложение?"
category: uikit
order: 73
---

Пользователь запускает приложение касанием его иконки на экране «Домой». Кроме этого, если приложение запросило определённые события (например, поддерживает одну из возможностей Background Modes), система может запустить его в фоне для обработки этих событий: приложение сразу переходит в состояние `Background`, а не на передний план.

Причину запуска можно определить: при использовании сцен UIKit передаёт в `scene(_:willConnectTo:options:)` объект `ConnectionOptions` (например, запрос открыть `URL`), без сцен — словарь `launchOptions` в `application(_:didFinishLaunchingWithOptions:)`. Ключи в словаре есть только для тех возможностей, которые приложение поддерживает.
