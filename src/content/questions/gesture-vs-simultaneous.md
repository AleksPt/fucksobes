---
title: "В чём разница между .gesture и .simultaneousGesture?"
category: swiftui
order: 51
---

Оба модификатора добавляют жест к view, но по-разному ведут себя, когда рядом есть другой жест — например, встроенный жест у кнопки или у родительской/дочерней view.

- **`.gesture(_:)`** — добавляет жест **с приоритетом**: если он распознаётся, он «перехватывает» событие и не даёт сработать другим жестам той же или вложенной view (в том числе, например, `.onTapGesture` кнопки внутри). Жесты конкурируют, и срабатывает только один.
- **`.simultaneousGesture(_:)`** — добавляет жест, который может распознаваться **одновременно** с другими жестами той же иерархии, не блокируя их. Оба жеста получают события и могут сработать вместе.

```swift
Button("Нажми") { print("tap") }
    .simultaneousGesture(
        DragGesture().onChanged { _ in print("drag") }
        // и обычный tap кнопки, и drag сработают независимо
    )

Button("Нажми") { print("tap") }
    .gesture(
        DragGesture().onChanged { _ in print("drag") }
        // перетаскивание перехватит событие, tap кнопки может не сработать
    )
```

Практическое применение `.simultaneousGesture` — когда нужно добавить свой жест (например, отслеживание перетаскивания или долгого нажатия для аналитики), не мешая штатному поведению view, на которую он навешен, — например, не блокируя тап по кнопке или скролл списка.
