---
title: "Можно ли реализовать Copy-on-Write для кастомной структуры?"
category: memory
order: 54
---

Да. Для этого используют класс-бэкенд для хранения данных и проверку количества ссылок на него. Структура хранит ссылку на этот класс, а перед любой мутацией проверяет, что владеет им единолично: `isKnownUniquelyReferenced(&storage)`. Если ссылок больше одной, создаётся копия хранилища, и изменения вносятся уже в неё.

```swift
final class Storage { var items: [Int] }

struct MyArray {
    private var storage = Storage(items: [])

    mutating func append(_ x: Int) {
        if !isKnownUniquelyReferenced(&storage) {
            storage = Storage(items: storage.items)   // копируем при записи
        }
        storage.items.append(x)
    }
}
```

Так копирование при присваивании стоит `O(1)` (копируется только ссылка), а полная копия делается лишь при первой записи. Тот же подход нужен для собственной хеш-таблицы: буфер с данными лежит в классе, а перед каждой мутацией (вставка, удаление, изменение значения) выполняется проверка на единственную ссылку. Стандартные `Array`, `Dictionary`, `Set` и `String` устроены именно так.
