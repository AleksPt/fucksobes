**Инкапсуляция** в Swift достигается через **модификаторы доступа**:

1. **`open`** — доступно из любого модуля; можно наследовать и переопределять в других модулях.
2. **`public`** — доступно из любого модуля; нельзя наследовать и переопределять вне модуля.
3. **`internal`** (по умолчанию) — доступно только внутри одного модуля.
4. **`fileprivate`** — доступно только внутри одного файла.
5. **`private`** — доступно только внутри одной области видимости (класса, структуры, расширения).
