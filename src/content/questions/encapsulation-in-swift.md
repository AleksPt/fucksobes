**Инкапсуляция** в Swift достигается через **модификаторы доступа**

1. **`open`**
    - Доступно из любого модуля.
    - Можно наследовать и переопределять в других модулях.
2. **`public`**
    - Доступно из любого модуля.
    - Нельзя наследовать и переопределять вне модуля.
3. **`internal`** (по умолчанию)
    - Доступно только внутри одного модуля.
4. **`fileprivate`**
    - Доступно только внутри одного файла.
5. **`private`**
    - Доступно только внутри одной области видимости (класса, структуры, расширения).
