---
title: "Что такое вывод типов (type inference)?"
category: swift
order: 128
---

Вывод типов — способность компилятора самому определить тип значения или выражения по контексту, поэтому его не нужно указывать явно. Swift при этом остаётся статически типизированным: тип всегда известен на этапе компиляции.

```swift
let name = "Hello"       // String
let count = 42           // Int
let price = 9.99         // Double
let flag = count > 10    // Bool

let names: [String] = [] // здесь тип нужен: по пустому литералу его не вывести
```

Для литералов действуют типы по умолчанию: целые — `Int`, дробные — `Double`, строки — `String`. Тип можно указать явно, когда он нужен для контекста (`let x: Float = 1`), когда его нельзя вывести или когда важна читаемость. Вывод типов работает и для замыканий (`items.map { $0 * 2 }`), но слишком сложные выражения замедляют компиляцию, и тогда компилятору помогают, указывая тип явно.
