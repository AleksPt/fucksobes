category: uikit
order: 59
---

**Можно переопределить метод ****`hitTest(_:with:)`**** в родительском представлении**, чтобы перенаправить события на подвиды, игнорируя свойство `isUserInteractionEnabled`. **И вернуть в ручную сабвьюхи вернуть нужную которая должна обработать.**

- Перекрыть обработку событий через метод **`hitTest(_:with:)`**.
- Использовать `UIGestureRecognizer`.

Гесты работают независимо от свойства `isUserInteractionEnabled`, если они добавлены к конкретным подвидам.

- Создать перекрывающее представление для захвата событий.
- Включить `isUserInteractionEnabled = true` для конкретных подвидов.
