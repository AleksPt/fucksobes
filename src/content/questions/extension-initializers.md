---
title: "Какие из инициализаторов мы можем добавить в extension?"
category: swift
order: 64
---

В extension можно добавлять новые инициализаторы к существующим типам, но с ограничениями для классов: расширение может добавить convenience-инициализаторы, а designated-инициализаторы и деинициализаторы должны быть в исходной реализации класса.

Для структур есть два полезных момента. Если значимый тип задаёт значения по умолчанию для всех хранимых свойств и не определяет собственных инициализаторов, то из инициализатора в extension можно вызвать его инициализатор по умолчанию и memberwise-инициализатор. Если структура объявлена в другом модуле, новый инициализатор до обращения к `self` обязан делегировать инициализатору из определяющего модуля.

```swift
extension Rect {
    init(center: Point, size: Size) {
        let origin = Point(x: center.x - size.width / 2,
                           y: center.y - size.height / 2)
        self.init(origin: origin, size: size)
    }
}
```
