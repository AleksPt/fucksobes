---
title: "Работает ли ARC со структурами?"
category: memory
order: 68
---

Сама структура ARC не управляется: у неё нет счётчика ссылок, она копируется по значению и живёт там, где лежит (стек, внутри другого объекта, в буфере массива). Но ARC работает с её содержимым: если поля структуры — ссылочные типы (экземпляры классов, замыкания, а также буферы `Array`, `String`, `Dictionary`), то при копировании структуры для каждого такого поля выполняется `retain`, а при уничтожении копии — `release`.

```swift
struct User {
    var name: String        // содержит ссылку на буфер (для длинных строк)
    var tags: [String]      // ссылка на буфер массива
    var avatar: Image       // класс: ссылка
}
```

Каждая копия `User` увеличивает счётчики нескольких объектов. Поэтому большая структура с множеством ссылочных полей копируется дорого, хотя выглядит как «просто значение», а структура, состоящая только из простых типов (числа, `Bool`), ARC не задействует вообще. Это одна из причин осторожно относиться к «толстым» структурам и избегать лишних копий.
