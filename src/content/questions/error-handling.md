title: "Как обрабатывать ошибки"

Ошибки в Swift — значения типов, соответствующих протоколу `Error` (для этого хорошо подходят перечисления со связанными значениями). Ошибку бросают через `throw`, а функцию, которая может её бросить, помечают `throws`. Перед вызовом такой функции пишется `try` (или `try?` / `try!`).

Есть четыре способа обработки:

- пробросить ошибку вызывающему коду (функция сама помечена `throws`);
- обработать в `do`-`catch`: ошибка сопоставляется с ветками `catch`;
- преобразовать в опционал через `try?` (при ошибке результат `nil`);
- утверждать, что ошибки не будет, через `try!` (если ошибка всё же случится — ошибка времени выполнения).

```swift
enum VendingMachineError: Error {
    case outOfStock
    case insufficientFunds(coinsNeeded: Int)
}

do {
    try buyFavoriteSnack(person: "Alice")
} catch VendingMachineError.insufficientFunds(let coins) {
    print("Нужно ещё \(coins) монет")
} catch {
    print("Ошибка: \(error)")
}
```

Для очистки ресурсов независимо от способа выхода из блока (ошибка, `return`, `break`) используется `defer`. В отличие от исключений во многих языках, обработка ошибок в Swift не раскручивает стек вызовов, поэтому `throw` по стоимости сопоставим с `return`.
