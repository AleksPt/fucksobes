title: "Как устроены словари"
category: algorithms

---

`Dictionary` — хеш-таблица (a type of hash table), где запись идентифицируется ключом; ключ должен быть `Hashable`. Значение ищут по ключу через subscript, который возвращает опционал: ключа может не быть. Присвоение по существующему ключу перезаписывает значение, по новому — добавляет пару, присвоение `nil` — удаляет.

Порядок пар не определён: он стабилен между мутациями, но в остальном непредсказуем. Если нужен порядок и не нужен быстрый поиск по ключу, документация предлагает `KeyValuePairs`.
