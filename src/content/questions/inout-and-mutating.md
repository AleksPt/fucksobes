---
title: "Ключевые слова inout и mutating"
category: swift

---

`inout` помечает параметр функции: значение передаётся внутрь, функция может его изменить, и после возврата новое значение заменяет исходное у вызывающего. Параметры функций по умолчанию константы, а аргументы передаются по значению. Аргумент inout — только переменная, при вызове перед ней ставится `&`. Такие параметры не могут иметь значения по умолчанию, а вариативные параметры не могут быть `inout`.

Формально это copy-in copy-out: значение копируется при вызове, в теле изменяется копия, при возврате она присваивается оригиналу. Оптимизация: если аргумент хранится по физическому адресу, используется тот же участок памяти (call by reference).

`mutating` ставится перед `func` в методе структуры или перечисления. По умолчанию методы значимых типов не могут менять их свойства; `mutating` разрешает это (в том числе присвоить `self` новый экземпляр). Вызвать такой метод на константе (`let`) типа-структуры нельзя.

```swift
func swapTwoInts(_ a: inout Int, _ b: inout Int) {
    (a, b) = (b, a)
}

struct Point {
    var x = 0.0, y = 0.0
    mutating func moveBy(x dx: Double, y dy: Double) {
        x += dx
        y += dy
    }
}
```
