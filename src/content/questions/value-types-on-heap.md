---
title: "Могут ли value типы храниться на куче"
category: memory
order: 7
---

Да: value type описывает семантику копирования, а не место хранения. Например, `String` хранит содержимое символов косвенно, на куче, поэтому создание такой строки может требовать выделения памяти в куче.

Другой случай: большое значение в переменной протокольного типа не помещается во внутренний буфер existential container (три слова), и для него выделяется память на куче. Это можно обойти, реализовав структуру с косвенным хранилищем и copy-on-write.
