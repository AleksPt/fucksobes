---
title: "Как отменить коммит, что такое rebase"
category: tooling
order: 2
---

Отменить коммит можно двумя способами:

- `git revert <commit>` создаёт **новый** коммит, обращающий изменения. История сохраняется, поэтому способ безопасен для уже опубликованных коммитов.
- `git reset` двигает `HEAD` назад: `--soft` оставляет изменения в индексе, `--mixed` (по умолчанию) в рабочей копии без индексации, `--hard` отбрасывает их полностью.

```bash
git reset --soft HEAD~1   # отменить последний коммит, оставив изменения
git revert HEAD           # отменить коммит новым коммитом
```

`git rebase` переигрывает коммиты текущей ветки поверх другого базового коммита, например `git rebase main` переносит ветку на актуальный конец `main`. История получается линейной, но коммиты создаются заново, поэтому не стоит делать rebase веток, на которые уже опираются другие.
