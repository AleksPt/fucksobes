---
title: "Что такое Memory Layout?"
category: memory
order: 11
---

Способ организации и размещения данных в памяти для конкретного объекта, структуры или класса. Всё это происходит автоматически.

Memory layout описывает:

1. **Размер (size)** — сколько байтов занимает объект в памяти.
2. **Выравнивание (alignment)** — минимальный шаг, с которого должен начинаться объект в памяти.
3. **Смещение (offset)** — позиция каждого свойства относительно начала объекта.
