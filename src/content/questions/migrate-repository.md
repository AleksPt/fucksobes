---
title: "Как перенести репозиторий с одного сервиса на другой с сохранением истории коммитов?"
category: git
order: 11
---

История хранится в самом репозитории, поэтому достаточно перенести все ссылки (ветки и теги) в новый remote:

```bash
git clone --mirror <URL-старого-репозитория>
cd <репозиторий>.git
git remote set-url origin <URL-нового-репозитория>
git push --mirror
```

Опция `--mirror` копирует полный набор ссылок: все ветки, теги и коммиты. Новый репозиторий на целевом сервисе должен быть создан заранее и быть пустым. После отправки проверяют, что ветки, теги и число коммитов совпадают, а участникам сообщают новый URL, который они прописывают командой `git remote set-url`.

Такой перенос не затрагивает то, что живёт не в git, а на самом сервисе: issues, pull request, настройки веток, секреты и CI-конфигурацию, поэтому их переносят отдельными средствами (импорт или API).
