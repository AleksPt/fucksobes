---
title: "Weak — это опционал или нет?"
category: memory
order: 30
---

Да, `weak`-ссылка — это опциональная переменная: она всегда объявляется через `var` (не `let`) и имеет опциональный тип. Когда экземпляр освобождается, ARC автоматически записывает в неё `nil`.

```swift
class Owner { weak var friend: Friend? }
```

`unowned`, напротив, не делает значение опциональным: ARC никогда не обнуляет такую ссылку.
