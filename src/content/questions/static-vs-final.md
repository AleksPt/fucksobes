---
title: "В чём разница между static и final?"
category: swift
order: 133
---

Это модификаторы для разных целей.

- `static` делает свойство или метод принадлежащими самому типу, а не экземпляру: вызывают их через имя типа (`Config.shared`), а не через объект. В классах `static` эквивалентен `final class`, то есть переопределить такой член в подклассе нельзя (в отличие от `class`).
- `final` запрещает наследование класса или переопределение конкретного метода, свойства или сабскрипта в подклассах.

```swift
final class Service {              // от Service нельзя наследоваться
    static let shared = Service()  // член типа
    final func run() {}            // нельзя переопределить (лишне в final-классе)
}
```

`final` помогает компилятору вызывать методы напрямую, без таблицы виртуальных методов, что чуть быстрее, и явно выражает намерение. `static` описывает, где живёт член: у типа или у экземпляра.
