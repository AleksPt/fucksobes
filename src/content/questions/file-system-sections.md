в **Documents** обычно хранятся пользовательские файлы, такие как PDF, текстовые документы, изображения, и другие данные, которые должны быть доступны пользователю.

**Library**<br>Делится на несколько разделов:

- **Preferences**: Настройки приложения (UserDefaults и подобные данные).
- **Caches**: Временные данные, которые можно безопасно удалить, такие как кэш изображений или данных сети.

**tmp** используется для временного хранения файлов. Это место для логов, временных данных загрузки или любых других файлов, которые можно удалить.

**Название приложения .app**

- **Описание**: Это директория с самим приложением (Bundle), в которой находятся все ресурсы, поставляемые вместе с приложением:
- Музыка, изображения, шрифты и другие встроенные файлы.
- Скомпилированный код приложения.
