title: "Что для тебя чистый код"
category: architecture
order: 13
---

- **Понятные названия.** Используй осмысленные имена для переменных, функций и классов.
- **Простота.** Избегай излишней сложности, пиши ровно столько, сколько нужно.
- **Комментарии.** Документируй только сложные или неочевидные места.
- **Соблюдение стандартов.** Следуй общепринятым гайдлайнам, например Swift API Design Guidelines.
- **Тестируемость.** Пиши код, который легко покрыть тестами.
- **Отказ от дублирования.** Повторяющийся функционал реализуй через переиспользование.
- **Чистота зависимостей.** Используй dependency injection, чтобы уменьшить связность.
