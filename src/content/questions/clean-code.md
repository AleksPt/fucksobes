**Понятные названия:** Используй осмысленные имена для переменных, функций и классов.

**Простота:** Избегай излишней сложности, пиши ровно столько, сколько нужно.

**Комментирование:** Документируй только сложные или неочевидные места.

**Соблюдение стандартов:** Следуй общепринятым гайдлайнам, таким как Swift API Design Guidelines.

**Тестируемость:** Пиши код, который легко покрыть тестами.

**Отказ от дублирования:** Реализуй повторяющийся функционал через переиспользование.

**Чистота зависимостей:** Используй dependency injection, чтобы минимизировать связность.
