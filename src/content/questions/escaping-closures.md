---
title: "Что такое escaping и nonescaping замыкания. В каких случаях надо использовать escaping и почему?"
category: swift
order: 23
---

Замыкание «убегает» (escapes) из функции, когда оно передано как аргумент, но вызывается после возврата из функции. Параметр функционального типа по умолчанию nonescaping; чтобы разрешить замыканию пережить вызов, перед типом параметра пишется `@escaping`. Без этого атрибута сохранение замыкания за пределы функции — ошибка компиляции.

Использовать `@escaping` нужно, когда замыкание сохраняется или вызывается позже: например, добавляется в массив, объявленный вне функции, или является completion handler асинхронной операции (функция возвращается сразу после старта, а замыкание вызывается по завершении).

```swift
var completionHandlers: [() -> Void] = []
func add(completionHandler: @escaping () -> Void) {
    completionHandlers.append(completionHandler)
}
```

Если убегающее замыкание ссылается на `self` экземпляра класса, легко случайно создать цикл сильных ссылок; поэтому `self` нужно указывать явно (`self.x`) или включить в список захвата. Неубегающее замыкание может обращаться к `self` неявно.
