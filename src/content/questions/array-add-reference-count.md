---
title: "Что происходит со ссылками при добавлении объекта в массив?"
category: memory
order: 46
---

Увеличивается счетчик ссылок объекта.

---

его **счетчик ссылок увеличивается на 1**. Это связано с тем, что коллекция **удерживает объект** до тех пор, пока он находится внутри неё.

Для хранения делегатов рекомендуется использовать слабые ссылки (weak), чтобы избежать циклических зависимостей, с помощью NSPointerArray или кастомных решений.
