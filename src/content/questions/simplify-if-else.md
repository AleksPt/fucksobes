---
title: "Как упростить код с if-else, который вызывает разные функции в зависимости от возраста?"
category: swift
order: 118
---

```swift
if age >= 18 {
    driveCar()
} else {
    doNotDrive()
}
```

Код корректен, но его можно записать короче тернарным оператором `условие ? A : B`:

```swift
age >= 18 ? driveCar() : doNotDrive()
```

Тернарный оператор хорош для простого выбора между двумя значениями (`let status = age >= 18 ? "adult" : "minor"`). Для вызовов функций с побочными эффектами обычный `if-else` часто читается лучше, поэтому здесь это вопрос стиля. Разумнее сделать условие осмысленным: вынести проверку в именованное значение (`var canDrive: Bool { age >= 18 }`) или константу (`let legalAge = 18`), чтобы убрать «магическое число». С Swift 5.9 `if` и `switch` можно использовать как выражения: `let text = if age >= 18 { "adult" } else { "minor" }`.
