---
title: "Что такое Core Data? Когда и для чего её используют?"
category: data-storage
order: 18
---

Core Data — фреймворк Apple для управления графом объектов модели и их сохранения. Он не является базой данных как таковой: это слой над хранилищем (по умолчанию SQLite), который берёт на себя создание, изменение, связи между объектами, валидацию, отмену изменений и загрузку по запросу.

Его используют, когда приложению нужно хранить структурированные данные с отношениями между сущностями, искать и сортировать их (предикаты и `NSFetchRequest`), работать с большими наборами без загрузки в память целиком и мигрировать схему между версиями. Для нескольких настроек достаточно `UserDefaults`, а для секретов нужен Keychain. Core Data интегрируется с `NSFetchedResultsController` и iCloud-синхронизацией через `NSPersistentCloudKitContainer`.
