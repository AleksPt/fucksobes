---
title: "Как сравнить 2 объекта по ссылке"
category: swift

---

Оператором тождественности `===` (и `!==` для противоположной проверки). Он возвращает `true`, если две ссылки указывают на один и тот же экземпляр класса, то есть на один и тот же адрес в памяти.

```swift
class Fruit { var name = "Banana" }

let a = Fruit()
let b = a
let c = Fruit()

a === b   // true: одна и та же ссылка
a === c   // false: разные объекты с одинаковым содержимым
```

Не путать с `==`: это оператор равенства, он сравнивает значения и работает для типов, подписанных на `Equatable`. Два разных объекта могут быть равны по `==` и при этом не тождественны по `===`. Оператор `===` применим только к экземплярам классов (ссылочным типам), для структур и перечислений он не имеет смысла: значения копируются.
