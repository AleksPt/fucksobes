---
title: "В чём разница между Void и ()?"
category: swift
order: 131
---

`Void` — это псевдоним пустого кортежа: в стандартной библиотеке объявлено `typealias Void = ()`. Поэтому как тип они полностью равнозначны: `() -> Void` и `() -> ()` — один и тот же тип функции.

Разница в том, что `()` ещё и значение — единственное значение пустого кортежа, а `Void` — только имя типа. Функция без явного возвращаемого значения возвращает `Void`, то есть `()`:

```swift
func log(_ message: String) { print(message) }   // возвращает ()
let result: Void = log("hi")                     // result == ()

let unit: () = ()                                // значение
```

По конвенции в объявлениях типов пишут `Void` (`completion: () -> Void`) для читаемости, а `()` — когда нужно значение или пустой список параметров.
