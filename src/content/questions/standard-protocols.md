---
title: "Какие протоколы дефолтные есть в свифте кроме Hashable? И что они значат"
category: swift
order: 59
---

Основные протоколы стандартной библиотеки:

- **`Equatable`** — значения можно сравнивать на равенство через `==` и `!=`; является базовым для `Hashable` и `Comparable`. Реализация синтезируется автоматически, если тип отвечает условиям и соответствие объявлено в самом объявлении типа.
- **`Comparable`** — типы с естественным порядком; требуют `<` и `==`, остальные операторы сравнения (`!=`, `>`, `<=`, `>=`) даёт стандартная библиотека. Для таких элементов доступен `sort()` без аргументов.
- **`Identifiable`** — стабильная идентичность значения (свойство `id`); для классов есть реализация по умолчанию на основе `ObjectIdentifier`, уникальная только на время жизни объекта.
- **`CustomStringConvertible`** — собственное текстовое представление через `description`; его используют `print(_:)` и `String(describing:)`.
- **`Codable`** — псевдоним `Decodable & Encodable`: тип умеет преобразовываться во внешнее представление и обратно.
- **`CaseIterable`** — коллекция всех значений типа `allCases`; для перечислений без associated values компилятор синтезирует её автоматически.
