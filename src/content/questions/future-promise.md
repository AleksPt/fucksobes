---
title: "Что такое Future/Promise?"
category: concurrency
order: 82
---

Future и Promise — два связанных понятия для работы с результатом, который появится позже. Promise — «обещание», через которое производитель записывает результат (или ошибку) один раз; Future — «читающая» сторона, объект, который представляет ещё не готовое значение. Подписчик получает результат, когда он будет установлен, и не блокирует поток в ожидании.

В Combine это `Future<Output, Failure>`: он принимает замыкание с `promise`, вызывает его один раз и после этого издаёт одно значение или ошибку.

```swift
let future = Future<Int, Never> { promise in
    DispatchQueue.global().async { promise(.success(42)) }
}
```

Future начинает работу сразу при создании (а не при подписке) и кэширует результат для всех подписчиков. В современном Swift ту же задачу решают `async/await` и `withCheckedContinuation`. В других библиотеках (например, PromiseKit) `Promise` и `Future` могут называть один и тот же тип.
