---
title: "Какие операторы передачи управления есть в Swift?"
category: swift
order: 114
---

Операторы передачи управления меняют порядок выполнения кода:

- `break` — немедленно завершает цикл или `switch`;
- `continue` — прекращает текущую итерацию цикла и начинает следующую;
- `return` — выходит из функции и возвращает значение;
- `throw` — выбрасывает ошибку из функции с `throws`;
- `fallthrough` — в `switch` продолжает выполнение следующего `case` без проверки его условия.

```swift
let n = 5
var text = "\(n) —"
switch n {
case 2, 3, 5, 7:
    text += " простое,"
    fallthrough
case 10:
    text += " и выполнился case 10"
default:
    text += " другое"
}
// 5 — простое, и выполнился case 10
```

В Swift `case` в `switch` не «проваливается» сам, как в C: после совпавшего `case` выполнение выходит из `switch`, поэтому `break` в конце не нужен, а `fallthrough` нужен явно. Также есть `guard … else`, где в теле нужен один из операторов выхода, и метки (`outer: for …`), позволяющие выйти из внешнего цикла командой `break outer`.
