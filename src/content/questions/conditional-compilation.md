---
title: "Что такое условная компиляция? Для чего она используется?"
category: swift
order: 104
---

Условная компиляция включает или исключает участки кода на этапе сборки, поэтому исключённый код не попадает в бинарный файл. В Swift для этого служит директива `#if … #elseif … #else … #endif` с флагами компиляции.

```swift
#if DEBUG
print("отладочный вывод")
#endif

#if os(iOS)
import UIKit
#elseif os(macOS)
import AppKit
#endif

#if targetEnvironment(simulator)
// код только для симулятора
#endif
```

Доступные условия: собственные флаги (`-D FLAG` в `Active Compilation Conditions`), `DEBUG`, платформа (`os(...)`), архитектура (`arch(...)`), версия языка и компилятора (`swift(>=5.9)`, `compiler(>=5.9)`), возможность импорта модуля (`canImport(...)`) и симулятор (`targetEnvironment(simulator)`).

Используют для отладочного кода, поддержки нескольких платформ в общей кодовой базе, разных конфигураций сборки (staging и production) и версий Swift. Код внутри исключённой ветки должен быть синтаксически корректным. Не стоит злоупотреблять: такой код сложнее тестировать и читать.
