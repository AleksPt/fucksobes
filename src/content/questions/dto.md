---
title: "Что такое DTO?"
category: architecture
order: 59
---

DTO (Data Transfer Object) — простой объект для передачи данных между слоями или системами, обычно между сервером и приложением. Он содержит только поля (и, как правило, соответствие `Codable`), без бизнес-логики.

```swift
struct UserDTO: Decodable {
    let id: Int
    let full_name: String
    let avatar_url: String?
}

struct User {                  // доменная модель
    let id: Int
    let name: String
    let avatar: URL?
    init(dto: UserDTO) { ... }  // маппинг
}
```

Зачем нужен: формат ответа сервера (названия полей, optional, вложенность) отделяется от доменных моделей приложения. Изменение API затрагивает только DTO и маппер, а не весь код. В приложении данные обычно проходят цепочку: `DTO (сеть)` → `Domain model` → `ViewModel`. Минусы: дополнительный код и мапперы, дублирование полей, поэтому в небольших приложениях иногда используют одну модель для всех слоёв.
