---
title: "Что такое Memory Graph?"
category: tooling
order: 23
---

Memory Graph Debugger — инструмент Xcode для анализа объектов в памяти запущенного приложения. Включается кнопкой **Debug Memory Graph** на панели отладки: Xcode делает снимок кучи и показывает все живые объекты и ссылки между ними в виде графа.

Он помогает:

- найти утечки памяти: объекты, которые остались в куче, хотя на них ничего не ссылается (помечаются восклицательным знаком в навигаторе);
- обнаружить циклы сильных ссылок (retain cycles): граф показывает, какие объекты удерживают друг друга;
- понять, кто именно удерживает объект, и посмотреть тип связи (сильная, слабая, unowned);
- увидеть количество экземпляров типов, например, сколько контроллеров осталось после закрытия экранов.

Чтобы видеть стеки создания объектов, включают **Malloc Stack Logging**. Для более глубокого профилирования (динамика выделений, рост памяти) используют Instruments (Allocations, Leaks).
