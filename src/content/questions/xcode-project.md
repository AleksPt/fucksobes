title: "Что такое Project в Xcode?"
category: tooling

---

**Project** (`.xcodeproj`) — репозиторий файлов и ресурсов, необходимых для сборки продукта: исходный код, библиотеки, фреймворки, изображения, файлы Interface Builder. Проект хранит связи между этими элементами и задаёт настройки по умолчанию для всех таргетов, которые в нём находятся.

`.xcodeproj` — не файл, а пакет (папка, которую Finder показывает единым элементом). Внутри:

- **`project.pbxproj`** — текстовый файл (по сути список объектов), в котором хранится всё описание проекта: ссылки на исходники и ресурсы, группировка файлов в навигаторе, список таргетов, зависимости между ними и настройки сборки. Именно в нём чаще всего возникают конфликты слияния при командной работе.
- **`xcuserdata/`** — состояние конкретного разработчика: открытые файлы, выбранный таргет, breakpoints, схемы, если их сохранили только для себя. Эту папку добавляют в `.gitignore`.
- **`xcshareddata/`** — общие для команды настройки: схемы и breakpoints, помеченные как shared, чтобы они попадали в git и были одинаковыми у всех.

Один проект может содержать несколько **таргетов** (например, основное приложение, расширение и юнит-тесты), которые используют общие файлы, но собираются по-разному.
