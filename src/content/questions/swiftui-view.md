---
title: "Что такое View в SwiftUI"
category: swiftui
order: 2
---

`View` — протокол, тип которого описывает часть пользовательского интерфейса приложения и предоставляет модификаторы для его настройки. Единственное обязательное требование — вычисляемое свойство `body`, возвращающее содержимое view.

```swift
struct MyView: View {
    var body: some View {
        Text("Hello, World!")
    }
}
```

`body` собирают из встроенных view SwiftUI и своих view, образуя иерархию. Модификаторы — методы с реализацией по умолчанию: они оборачивают view в новую view с нужными свойствами (например, `Text("Hello").opacity(0.5)`).
